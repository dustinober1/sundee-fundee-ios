# Coach Domain

- Training decisions are deterministic: exercise selection, sets, reps, loads, rest, substitutions, cycle multipliers, recovery guidance, and plan reshuffles come from domain services.
- The on-device model is copy-only. It may rewrite deterministic facts into friendlier user-facing summaries, tips, and explanations.
- The coaching pipeline is: Deterministic Planner → Decision Explainer → AI Copy Editor → Validator + Fallback.
- `DeterministicCoachService` is the source of truth for workout structure and acceptable fallback copy.
- `CoachDecisionPacket` carries compact, sanitized facts to prompt builders.
- `CoachPromptPack` owns prompt versions and hard rules.
- `CoachCopyValidator` rejects model copy that invents exercises, mentions weights/reps/percentages, uses medical language, or exceeds format limits.
- Rejected, unavailable, or weak AI copy falls back to deterministic copy without user-visible failure.
- Substitutions remain deterministic and are not generated by the model.
- Deterministic reason codes power user-facing rationale so the app never asks the model to infer why a decision was made.
