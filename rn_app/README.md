# Sundee-Fundee Mobile (Expo) - skeleton

This folder contains an Expo-managed React Native skeleton for the Sundee-Fundee app.

Chosen runtime: Expo (managed)
Local DB: expo-sqlite (SQLite)

Commands:

1. npm install
2. npm start

Notes:
- This is an initial scaffold; continue by adding navigation, shared logic, and porting calculation utilities from the web/src folder.
