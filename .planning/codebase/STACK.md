# Technology Stack

This Flutter-based application uses:

- **Languages**: Dart (Flutter 3.4+ / Dart 3.11+)
- **Framework**: Flutter for cross-platform mobile, web, and desktop
- **State Management**: Riverpod (hooks_riverpod)
- **Routing**: GoRouter
- **Backend**: Firebase (Firestore, Auth, Storage, Analytics, Crashlytics)
- **Testing**: `flutter test` for unit/widget tests, `flutter analyze` for static analysis
- **Build Tools**: Flutter CLI, Gradle (Android), Xcode (iOS)
- **CI/CD**: Not visible in repo; likely GitHub actions or similar
- **Other**:
  - Firebase CLI (scripts in root: `deploy.sh`, `run_local.sh`)
  - `flutterfire` generated `firebase_options.dart`
