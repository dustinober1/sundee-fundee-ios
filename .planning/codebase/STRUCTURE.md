## Directory Purposes

**`SundeeFundee/Sources/SundeeFundeeKit/DomainLayer/`:**
- Purpose: Pure Swift business logic with zero framework dependencies
- Contains: Cycle phase calculations, benchmarks, challenges, exercises, injury models, AI workout generation, program templates, coach logic, intelligence (plateau detection, schedule reshuffling, substitution ranking, load analysis), analytics, export, celebration
- Key files: 34 Swift files across 14 subdirectories
- Examples:
  - `Cycle/CycleCalculations.swift` — phase calculation functions
  - `Benchmark/BenchmarkCatalog.swift` — predefined benchmarks
  - `Program/ProgramTemplateGenerator.swift` — program creation
  - `Coach/CoachMemory.swift` — deterministic coaching context
  - `Intelligence/PlateauDetector.swift` — strength plateaus
  - `Injury/InjuryModels.swift` — injury tracking and adaptation

**`SundeeFundee/Sources/SundeeFundeeKit/DataLayer/`:**
- Purpose: Abstract persistence; implementations for CloudKit, local storage, and mocks
- Contains: Protocols, actor-based clients, bundled content, sync queue, helpers
- Subdirectories:
  - `Protocols/`: `DataClientProtocol`, `ContentClientProtocol`, `HealthClientProtocol`
  - `Actors/`: `CloudKitClient` (production), `LocalDataClient` (guest mode), `HealthKitClient` (HealthKit queries)
  - `Mocks/`: `MockCloudKitClient`, `MockHealthKitClient` (testing)
  - `BundledContent/`: `BundledContentProvider` (fallback exercises, benchmarks, programs)
  - `Helpers/`: `CyclePhaseHelper`, `CyclePhaseCache` (observable cycle state)
  - `SyncQueue/`: `SyncQueue` (offline mutation queue), `NetworkMonitor` (connectivity), `PendingMutation` (pending op)
- Key files:
  - `DataClientFactory.swift` — thread-safe singleton for client switching
  - `DataClientProtocol.swift` — async generic fetch/save/delete interface

**`SundeeFundee/Sources/SundeeFundeeKit/UI/`:**
- Purpose: SwiftUI views, view models, design system, theme
- Contains: App entry, tab navigation, feature-specific views, view models, theme tokens
- Subdirectories:
  - `App/`: `SundeeFundeeApp.swift` (MainTabView struct, reusable tab navigation)
  - `Theme/`: `AppTheme.swift` (colors, spacing, typography)
  - `ViewModels/`: Feature-specific ViewModels (`AuthViewModel`, `DashboardViewModel`, `AnalyticsViewModel`, `BenchmarksViewModel`, `ExportViewModel`, `ActiveWorkoutSessionViewModel`, `PainTrackingViewModel`)
  - `Views/`: Feature views by domain:
    - `Dashboard/DashboardView.swift` — main dashboard
    - `Workouts/WorkoutsListView.swift`, `ActiveWorkoutView.swift` — workout logging
    - `Programs/ProgramsListView.swift` — program browser
    - `Maxes/MaxesListView.swift` — one-rep max tracking
    - `Analytics/AnalyticsView.swift`, charts (`VolumeChart`, `StrengthProgressionChart`, `FrequencyChart`, `CycleCorrelationChart`)
    - `Benchmarks/BenchmarksListView.swift` — benchmark scoring
    - `Challenges/ChallengesView.swift`, `CreateChallengeView.swift` — challenge tracking
    - `Cycle/CycleCalendarView.swift`, `SharkWeekBanner.swift` — cycle visualization
    - `Insights/InsightsView.swift` — AI coaching insights
    - `Pain/PainTrackingView.swift` — pain tracking
    - `Onboarding/OnboardingView.swift` — first-time setup
    - `Settings/SettingsView.swift` — preferences, sign out
    - `Export/ExportView.swift` — data export
    - `Share/WorkoutShareCardView.swift` — social sharing
  - `Models/`: `SharedModels.swift` (UI-only types)

## Naming Conventions

**Files:**
- PascalCase: `AuthViewModel.swift`, `DashboardView.swift`, `CycleCalculations.swift`
- Descriptive names: `LiveWorkoutActivityManager.swift` (noun + purpose)
- Protocol suffix: `DataClientProtocol.swift`, `AppleAuthClientProtocol.swift`
- Error types: `AuthError.swift`, suffixed with `Error`
- Test files: `CyclePhaseHelperTests.swift` (class name + "Tests")

**Directories:**
- PascalCase: `DomainLayer/`, `DataLayer/`, `UI/`
- Feature-based under Views: `Dashboard/`, `Workouts/`, `Programs/`, `Maxes/`, `Analytics/`, `Benchmarks/`, `Challenges/`, `Cycle/`, `Insights/`, `Pain/`, `Onboarding/`, `Settings/`, `Export/`, `Share/`
- Functional grouping: `Actors/` (actor-based clients), `Protocols/` (abstract interfaces), `Mocks/` (testing doubles), `Helpers/` (utilities), `BundledContent/` (reference data), `SyncQueue/` (offline sync)

**Types:**
- ViewModels: `{Feature}ViewModel` (e.g., `DashboardViewModel`, `AuthViewModel`)
- Views: `{Feature}View` (e.g., `DashboardView`, `ActiveWorkoutView`)
- Models: `{Entity}Record` for CloudKit models (e.g., `WorkoutRecord`, `ChallengeRecord`)
- Enums: PascalCase, semantic names (e.g., `CyclePhase`, `ExerciseValue`)
- Errors: `{Domain}Error` (e.g., `AuthError`, `DataError`)
- Protocols: `{Name}Protocol` (e.g., `DataClientProtocol`)

**Functions & Variables:**
- camelCase: `loadData()`, `saveWorkout()`, `userID`
- Computed properties: Pascal-like but lowercase start (e.g., `isAuthenticated`, `currentPhase`)
- Private: `_client` (underscore prefix for backing fields)
- Constants: UPPER_SNAKE_CASE (e.g., `guestUserID`, `isScreenshotMode`)

## Where to Add New Code

**New Feature (e.g., Hydration Tracker):**
- Core logic: `SundeeFundee/Sources/SundeeFundeeKit/DomainLayer/{Feature}/` (pure functions)
  - Example: `DomainLayer/Hydration/HydrationCalculations.swift`
- UI: `SundeeFundee/Sources/SundeeFundeeKit/UI/Views/{Feature}/`
  - Example: `UI/Views/Hydration/HydrationView.swift`, `UI/Views/Hydration/HydrationViewModel.swift`
- Models: `SundeeFundee/Sources/SundeeFundeeKit/Models/`
  - Add to or create new model file: `Models/Hydration.swift` (Codable model)
- Data persistence: Update `DataClientProtocol` if new record type needed
- Tests: `SundeeFundee/Tests/SundeeFundeeKitTests/DomainTests/{Feature}/` and `ViewModelTests/`
- Tab navigation: Update `MainTabView` in `UI/App/SundeeFundeeApp.swift`

**New Component/Reusable Module:**
- Shared UI component: `SundeeFundee/Sources/SundeeFundeeKit/UI/Components/` (if dir doesn't exist, create it)
  - Example: `UI/Components/CardView.swift`, `UI/Components/StatBadge.swift`
- Pure utility: `SundeeFundee/Sources/SundeeFundeeKit/Calculations/` (math, conversions)
  - Example: `Calculations/WeightConversion.swift` (kg ↔ lbs)

**New Data Model:**
- Shared type: `SundeeFundee/Sources/SundeeFundeeKit/Models/{Name}.swift`
- Conform to: `Codable`, `Sendable`, `Equatable` (for CloudKit serialization + Sendable concurrency)
- If CloudKit persistence: Register record type in CloudKit Dashboard (Development → Indexes → add `recordName` queryable index); deploy to Production

**Utilities:**
- Shared helpers: `SundeeFundee/Sources/SundeeFundeeKit/DataLayer/Helpers/` (DataLayer-specific)
  - Example: `DataLayer/Helpers/CyclePhaseHelper.swift`, `DataLayer/Helpers/DateFormatter+Extensions.swift`
- Extensions: `SundeeFundee/Sources/SundeeFundeeKit/{Layer}/Extensions/` or inline in relevant file
