## v1 Requirements — Final Status

### Recommendations

- [x] **RECOM-01**: User receives weight suggestions for next workout based on rules (e.g. 5lb increase)
  - **Outcome:** Validated — 70%/+5/-5 1RM logic implemented in recommendation engine; pre-filled weight inputs with Tooltip in workout flow
- [x] **RECOM-02**: System detects plateaus (3+ workouts without progress) and notifies user
  - **Outcome:** Validated — Per-exercise rep-failure plateau detection; pre-workout plateau modal with deload recommendation
- [x] **RECOM-03**: User sees confetti celebration when setting a new PR
  - **Outcome:** Validated — Full-screen PR confetti overlay (canvas-confetti) with haptic + sound, weight and volume PR types

### Charts

- [x] **CHART-01**: User can view line chart of 1RM progress over time per exercise
  - **Outcome:** Validated — Epley formula 1RM line chart with per-exercise selector, Recharts
- [x] **CHART-02**: User can view bar chart of weekly volume load
  - **Outcome:** Validated — Weekly volume bar chart (last 12 weeks) with Dexie data hooks
- [x] **CHART-03**: User can view workout frequency heatmap (GitHub style)
  - **Outcome:** Validated — 365-day workout frequency heatmap (react-activity-calendar v3)

### Sync

- [x] **SYNC-01**: User data automatically backs up to Supabase when online
  - **Outcome:** Validated — syncAfterWorkout hooked to workout completion; push/pull with offline queue
- [x] **SYNC-02**: User can restore data from cloud to a new device
  - **Outcome:** Validated — Auto-pull on auth + window focus; bulkPut merge strategy
- [x] **SYNC-03**: User sees visual indicator of sync status (synced, pending, offline)
  - **Outcome:** Validated — SyncStatusPopover in dashboard header with formatTimeAgo, offline banner

### Testing

- [x] **TEST-01**: E2E test verifies user can complete full workout flow
  - **Outcome:** Validated — workout-flow.spec.ts: onboarding → session → sets → complete → /dashboard (11/11 E2E pass)
- [x] **TEST-02**: E2E test verifies PR celebration triggers correctly
  - **Outcome:** Validated — pr-celebration.spec.ts: seeds 1RM in IDB, enters higher weight, asserts "New PR!" overlay
- [x] **TEST-03**: E2E test verifies data syncs to remote mock
  - **Outcome:** Validated — sync-verification.spec.ts: asserts sync_pending_workout_ids populated in localStorage
