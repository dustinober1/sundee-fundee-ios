    - Displays: "Adapting for: Luteal phase . Right knee (subacute) . Readiness 7/10"

    - Returns null if no adaptations apply

    - Four ConfigCards rows:
      1. **Time:** 15 min, 30 min, 45 min, 60 min (default: 30)
      2. **Focus:** Upper, Lower, Full Body, Push, Pull (default: Full Body)
      3. **Equipment:** Full Gym, Dumbbells Only, Bodyweight (default: Full Gym)
      4. **Energy:** Low, Medium, High (default: Medium)
    - Below cards: **AdaptationChip** showing automatic context
    - Auto-load context on mount:
      - Cycle phase: `getCycleRepo(isGuest).getPeriodLogs(uid)` + `getCycleRepo(isGuest).getCycleSettings(uid)` + `calculateCycleStatus()` -> cyclePhase (only if cycleTrackingEnabled)

      - Readiness: `getReadinessRepo(isGuest).getSurveyForDate(uid, today)` -> score
    - "Generate Workout" button at bottom:
      1. Check connectivity: `Network.getNetworkStateAsync()` (check BEFORE calling, per research anti-pattern)
      2. If online: call Cloud Function `functions().httpsCallable('generateWorkout')(context)`
      3. If offline: call `generateOfflineWorkout(context)` and show offline badge
      4. Navigate to preview screen with generated workout data (pass as route params or shared state)
      5. Show loading skeleton during generation (not spinner)
    - Error handling: catch Cloud Function errors, show toast, offer retry or offline fallback
    - Thread `uid` from `useSession()`
