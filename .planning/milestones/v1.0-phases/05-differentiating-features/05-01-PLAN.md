  <behavior>
    - RootErrorBoundary renders "Something went wrong" heading
    - RootErrorBoundary renders a "Reload App" link pointing to "/" with reloadDocument
    - RootErrorBoundary displays the error message from useRouteError when error is an Error instance
    - RootErrorBoundary displays status/statusText when error is a route error response
    - AppErrorBoundary renders "Something went wrong" heading
    - AppErrorBoundary renders a "Back to Dashboard" link pointing to "/"
    - AppErrorBoundary displays error message from useRouteError
  </behavior>
  <action>
    Write failing tests first (RED), then implement.

    **Tests:** Use vitest + @testing-library/react. Mock `useRouteError` and `isRouteErrorResponse` from `react-router`. Test that each boundary renders the expected heading text, error message, and recovery link.

    Note: `useRouteError` can only be called inside a component rendered as an `ErrorBoundary` by React Router. In tests, mock it via `vi.mock('react-router', ...)` to return a controlled error value.

    **RootErrorBoundary.tsx:**
    - Import `useRouteError`, `isRouteErrorResponse` from `react-router`
    - If route error response: show `${error.status} ${error.statusText}`
    - If Error instance: show `error.message`
    - Else: show "An unexpected error occurred."
    - Recovery: `<a href="/">Reload App</a>` (full page reload, not SPA navigation — use anchor tag, not Link)
    - Style with Art Deco theme: cream background, navy text, orange accent on button

    **AppErrorBoundary.tsx:**
    - Same error display logic as RootErrorBoundary
    - Recovery: `<Link to="/">Back to Dashboard</Link>` (SPA navigation since AppLayout may still be functional)
    - Import `Link` from `react-router`
    - Style consistently with RootErrorBoundary

    **CSS for both:** Center content vertically and horizontally, max-width 400px, card-style container with border-radius, recovery button styled as primary action (orange background, cream text).
  </action>
  <verify>
    <automated>cd pwa && npx vitest run src/routes/RootErrorBoundary.test.tsx src/routes/AppErrorBoundary.test.tsx</automated>
  </verify>
  <done>Both error boundary components render correct heading, error message, and recovery link. All tests pass.</done>
