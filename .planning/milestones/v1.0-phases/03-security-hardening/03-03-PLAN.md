<task type="auto">
  <name>Task 1: Add CSP headers, security headers, and Firestore rules reference to firebase.json</name>
  <files>firebase.json</files>
  <action>
Update `firebase.json` with two changes:

**Change 1: Add Firestore rules reference** at the top level (alongside "functions" and "hosting"):
```json
"firestore": {
  "rules": "firestore.rules"
}
```

**Change 2: Add a new entry to the `hosting.headers` array** targeting `"source": "**"` with three security headers. Place this entry FIRST in the headers array (before the Cache-Control entries, since more specific Cache-Control rules on `index.html` and `sw.js` will override for those paths):

```json
{
  "source": "**",
  "headers": [
    {
      "key": "Content-Security-Policy",
      "value": "default-src 'self'; script-src 'self' 'unsafe-inline' https://checkout.stripe.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https://*.stripe.com; connect-src 'self' https://*.googleapis.com https://*.firebaseio.com wss://*.firestore.googleapis.com https://checkout.stripe.com https://q.stripe.com https://r.stripe.com https://us-central1-sundee-fundee.cloudfunctions.net; frame-src https://checkout.stripe.com; object-src 'none'; base-uri 'self';"
    },
    {
      "key": "X-Frame-Options",
      "value": "SAMEORIGIN"
    },
    {
      "key": "X-Content-Type-Options",
      "value": "nosniff"
    }
  ]
}
```

Keep `'unsafe-inline'` in `script-src` and `style-src` per research — required for Vite/React SPA on static hosting (no nonce injection without SSR).

Preserve all existing firebase.json content (functions block, hosting rewrites, existing Cache-Control headers). Only ADD the firestore block and the new headers entry.

Validate the JSON is well-formed after editing: `node -e "JSON.parse(require('fs').readFileSync('firebase.json','utf8'))"`.
