3. **Email sign-up success** — toggle to sign-up mode, fill fields, submit, assert `createUserWithEmailAndPassword` called, assert `navigate('/verify-email')` called
4. **Google sign-in success** — click Google button, assert `signInWithGoogle` called, assert `navigate('/')` called
5. **Guest sign-in success** — click Guest button, assert `signInAnonymously` called, assert `navigate('/')` called
6. **Shows error on auth failure** — mock `signInWithEmailAndPassword` to reject with `{ code: 'auth/wrong-password' }`, submit form, assert "Incorrect password." text appears on screen
7. **Disables buttons while loading** — after submit, all buttons have disabled attribute

Use `@testing-library/react` `render`, `screen`, `fireEvent` (or `userEvent`). Wrap SignIn in a minimal mock router context if `useNavigate` requires it (use `MemoryRouter` from react-router).

**Important:** The SignIn component uses `useNavigate` from `react-router`. Either:
- Mock the module: `vi.mock('react-router', () => ({ useNavigate: () => mockNavigate }))`
- Or wrap in `<MemoryRouter>` — but since lazy loading expects `createBrowserRouter`, mocking is cleaner.
