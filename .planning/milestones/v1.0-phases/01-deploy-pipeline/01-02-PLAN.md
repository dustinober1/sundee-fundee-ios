User must complete three setup tasks that require dashboard access Claude cannot automate.

**Part A: Set 8 VITE_ GitHub Secrets**

Go to GitHub repo -> Settings -> Secrets and variables -> Actions -> New repository secret.

Create these 8 secrets with real values from Firebase Console (Project Settings -> General -> Your apps -> Web app config) and Stripe Dashboard:

1. `VITE_FIREBASE_API_KEY` — from Firebase config
2. `VITE_FIREBASE_AUTH_DOMAIN` — set to `sundeefundee.com` (will work after DNS is verified; safe to set now since `sundee-fundee.firebaseapp.com` is kept as fallback in Firebase Auth authorized domains)
3. `VITE_FIREBASE_PROJECT_ID` — from Firebase config
4. `VITE_FIREBASE_STORAGE_BUCKET` — from Firebase config
5. `VITE_FIREBASE_MESSAGING_SENDER_ID` — from Firebase config
6. `VITE_FIREBASE_APP_ID` — from Firebase config
7. `VITE_STRIPE_PUBLISHABLE_KEY` — Stripe Dashboard -> Developers -> API keys
8. `VITE_STRIPE_PRICE_ID` — Stripe Dashboard -> Products -> your product -> Pricing -> Price ID

**Part B: Custom Domain Setup**

1. Firebase Console -> Hosting -> Add custom domain -> enter `sundeefundee.com`
2. Firebase shows a TXT record for ownership verification -> add it at your DNS registrar
3. Wait for TXT verification (usually 1-2 hours, can take up to 24h)
4. After verified: Firebase shows two A record IPs -> add them at your DNS registrar
5. IMPORTANT: Remove any existing A or AAAA records for the root domain first
6. Firebase auto-provisions SSL (can take up to 24h after DNS propagation)
7. Optionally add `www.sundeefundee.com` as a second custom domain that redirects to root

**Part C: Firebase Auth + OAuth Domain Setup**

1. Firebase Console -> Authentication -> Sign-in method -> Authorized domains -> Add `sundeefundee.com`
2. Google Cloud Console -> APIs and Services -> Credentials -> OAuth 2.0 Client IDs -> select the web client
3. Add `https://sundeefundee.com` to Authorized JavaScript origins
4. Add `https://sundeefundee.com/__/auth/handler` to Authorized redirect URIs

Resume signal: Type "secrets and DNS done" when all 8 secrets are set and DNS records are added (SSL may still be provisioning).
