     - 192x192 -> `pwa/public/icons/icon-192.png`
     - 512x512 -> `pwa/public/icons/icon-512.png`
     - 180x180 -> `pwa/public/apple-touch-icon.png`

   - Logs each generated file path

3. Run the script: `node scripts/generate-icons.mjs`

4. Verify the generated PNGs are valid (non-zero file size, correct dimensions). If sharp/librsvg produces blank output due to display-p3 color space in the SVG, simplify the SVG colors to sRGB hex equivalents in a copy used only for icon generation, or resize with `--density` override.

5. Create `pwa/public/offline.html` — a self-contained HTML file with ALL CSS inline (no external dependencies). Content:
   - `<html lang="en">` with charset, viewport meta

   - Body: navy (#0D1A40) background, cream (#F4F0DF) text, centered vertically

   - Paragraph: "Check your connection and try again"
   - Button: "Try Again" with orange (#F2731A) background, cream text, calls `window.location.reload()` on click
   - No external images, fonts, or scripts — everything inline
   - Include the app logo as an inline SVG element (simplified version of favicon.svg) above the heading for branding
