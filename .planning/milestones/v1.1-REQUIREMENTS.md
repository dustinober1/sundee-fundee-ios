## v1.1 Requirements — Final Status

### Rebrand

- [x] **BRAND-01**: User sees "Sundee-Fundee" as the app name in browser tab titles, page metadata, and document title across routes
  - **Outcome:** Validated — Metadata/title updated in layout and route-level UX surfaces.
- [x] **BRAND-02**: User sees "Sundee-Fundee" in visible UI text (replacing brand-name "Strength" references)
  - **Outcome:** Validated — Onboarding and user-facing copy updated; frozen domain terms intentionally retained.
- [x] **BRAND-03**: App configuration/docs reflect the new app name
  - **Outcome:** Validated — `package.json`, `README.md`, and `CLAUDE.md` rebranded.

### PWA Foundation

- [x] **PWA-01**: App serves a valid web app manifest with required values
  - **Outcome:** Validated — `src/app/manifest.ts` serves `/manifest.webmanifest` with standalone metadata.
- [x] **PWA-02**: App icon set includes 192, 192 maskable, 512, and 180 apple-touch-icon assets
  - **Outcome:** Validated — Icons generated via Sharp and committed under `public/icons/`.
- [x] **PWA-03**: Service worker caches app shell and supports navigation fallback while excluding Supabase caching
  - **Outcome:** Validated — Serwist SW + `/offline` fallback with Supabase `NetworkOnly`.
- [x] **PWA-04**: iOS-specific PWA `<head>` tags are present
  - **Outcome:** Validated — Apple-capable meta tags and icon/title metadata applied in layout.
- [x] **PWA-05**: Supabase middleware excludes SW/manifest routes from auth processing
  - **Outcome:** Validated — Middleware matcher excludes PWA static/service-worker routes.
- [x] **PWA-06**: Existing 11 Playwright tests stay green after SW introduction (`serviceWorkers: 'block'`)
  - **Outcome:** Validated — Guard added in phase 6 and retained through phase 8 with 11/11 passing.

### Install Experience

- [x] **INSTALL-01**: Android users receive Add-to-Home-Screen install prompt via `beforeinstallprompt` deferral
  - **Outcome:** Validated — `useInstallPrompt` hook and install banner implemented.
- [x] **INSTALL-02**: iOS users can access Share → Add to Home Screen instructions in modal UI
  - **Outcome:** Validated — iOS install modal integrated into dashboard flow.

### Icon Enrichment

- [x] **ICON-01**: `OfflineBanner` uses Lucide `WifiOff` instead of inline SVG
  - **Outcome:** Validated — Inline SVG removed and replaced with Lucide icon.
- [x] **ICON-02**: Dashboard cards use contextual Lucide icons
  - **Outcome:** Validated — Trophy/Flame/BarChart2 added to dashboard card surfaces.
- [x] **ICON-03**: Active workout/logging pages use fitness-specific Lucide icons
  - **Outcome:** Validated — Dumbbell/Target/AlarmClockCheck/CircleCheck integrated.
- [x] **ICON-04**: Bottom navigation uses a consistent Lucide icon set aligned by tab purpose
  - **Outcome:** Validated — Workout tab icon finalized as `Activity`; set is semantically distinct.
