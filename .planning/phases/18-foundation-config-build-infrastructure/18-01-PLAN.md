3. Create `src/firebase/analytics.ts` — Analytics initialization:

   - Export `function initAnalytics(): void` (sync)
   - Call `analytics().setAnalyticsCollectionEnabled(true)`
   - Log `[Analytics] Initialized`

4. Create `src/firebase/init.ts` — Centralized Firebase initialization orchestrator:
   - Import `initAppCheck` from './appCheck'
   - Import `initCrashlytics` from './crashlytics'
   - Import `initAnalytics` from './analytics'
   - Import `initMessaging` from './messaging'
   - Export `async function initFirebase(): Promise<void>` that calls all four in order:
     1. `await initAppCheck()` (must be first — secures all subsequent calls)
     2. `initCrashlytics()` (sync)
     3. `initAnalytics()` (sync)
     4. `await initMessaging()` (async)

   - Log `[Firebase] All modules initialized`
