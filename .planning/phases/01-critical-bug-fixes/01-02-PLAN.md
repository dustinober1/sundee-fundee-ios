In the method that resolves after Apple sign-in (likely `resolveAfterAppleSignIn` or the sign-in completion handler), add batch userID migration:

2. Load the guest UUID from `KeychainHelper.loadGuestUserID()`
3. If guest UUID exists, fetch and update ALL SwiftData model types that have a userID/ownerID field. Audit all V12 models to find which ones carry a user identifier field. Based on research, these include at minimum: `User`, `CompletedWorkout`, `CompletedSet`, `InjuryProfile`, `PainLog`, `BenchmarkResult`, `ConditioningPR`, `GeneratedWorkoutRecord`, `EnrolledProgram`, `BarbellPreset`, `ExerciseBarMapping`. For each model type with a userID field:
   ```swift
   let descriptor = FetchDescriptor<ModelType>(predicate: #Predicate { $0.userID == guestUUID })
   let records = try modelContext.fetch(descriptor)
   for record in records { record.userID = appleUserID }
   ```
4. After all updates, call `try modelContext.save()`
5. On success: clear the pending flag (`UserDefaults.standard.removeObject(forKey: "guestMigrationPending")`) and delete the guest UUID from Keychain

Also add a check in `AppState` (or wherever app launch setup occurs): if `UserDefaults.standard.bool(forKey: "guestMigrationPending")` is true AND user is authenticated, re-run the migration.
