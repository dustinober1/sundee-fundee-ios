  <action>
Create `src/hooks/use-install-prompt.ts` with `'use client'` directive. This file exports two hooks:

**`useInstallPrompt()`** — Android `beforeinstallprompt` deferral:
1. Define `BeforeInstallPromptEvent` interface extending `Event` with `platforms: string[]`, `userChoice: Promise<{outcome: 'accepted'|'dismissed'}>`, and `prompt(): Promise<void>`.
2. Use `useState` for `deferredPrompt` (typed `BeforeInstallPromptEvent | null`, default `null`).
3. In `useEffect`:
   - If `localStorage.getItem('pwa-install-dismissed')` is truthy, return early.
   - If `window.matchMedia('(display-mode: standalone)').matches` is true, return early (already installed).
   - Add `beforeinstallprompt` event listener that calls `e.preventDefault()` (prevents Chrome mini-infobar) and stores the event via `setDeferredPrompt`.
   - Return cleanup function removing the listener.
4. `promptInstall()` async function: calls `deferredPrompt.prompt()`, awaits `userChoice`, if outcome is `'dismissed'` sets localStorage `'pwa-install-dismissed'` to `'1'`, then sets deferredPrompt to null.
5. `dismiss()` function: sets localStorage `'pwa-install-dismissed'` to `'1'`, sets deferredPrompt to null.
6. Return `{ canInstall: !!deferredPrompt, promptInstall, dismiss }`.

**`useIsIosInstallable()`** — iOS Safari detection:
1. Use `useState` for `show` (default `false`) and define `dismiss` function.
2. In `useEffect`:
   - Detect iOS via `/iPhone|iPad|iPod/i.test(navigator.userAgent)`.
   - Detect standalone via `window.matchMedia('(display-mode: standalone)').matches || ('standalone' in navigator && (navigator as { standalone?: boolean }).standalone === true)`.
   - Check `localStorage.getItem('ios-install-dismissed')`.
   - Set `show` to `true` only if iOS AND NOT standalone AND NOT dismissed.
3. `dismiss()` sets localStorage `'ios-install-dismissed'` to `'1'` and sets `show` to `false`.
4. Return `{ showIosPrompt: show, dismissIos: dismiss }`.

Use the exact code patterns from `08-RESEARCH.md` — they've been vetted. All browser API access is inside `useEffect` (SSR-safe).
