  <name>Task 1: Create InjuryAdaptationBanner widget</name>
  <files>flutter_app/lib/features/programs/presentation/widgets/injury_adaptation_banner.dart</files>
  <action>
    Create a new StatelessWidget that mirrors the structure of `CycleAdjustmentExplainer` but serves the injury adaptation context. The widget is a ConsumerWidget that reads `injuryAdaptationContextProvider`.

    **Widget behavior has three states:**

    **State A — Disclaimer not yet acknowledged (gate):**
    Render a prominent Card with:
    - Orange health_and_safety icon + bold title "Injury-Adapted Plan"
    - Disclaimer text: "This plan has been modified based on your injury profile. Exercises have been replaced with safer alternatives and recovery prep has been added. **This is not medical advice.** Consult a qualified healthcare professional before beginning or modifying any exercise program. Generated guidance is not a substitute for medical advice or physical therapy."
    - "I UNDERSTAND" ElevatedButton that calls `onAcknowledgeDisclaimer` callback
    - Card uses `Colors.orange.withValues(alpha: 0.08)` background tint

    **State B — Acknowledged, expanded:**
    Render a compact Card with:
    - Row: health_and_safety icon (orange) + "Plan adapted for {N} active injur{y/ies}"
    - Persistent reminder line: "Not medical advice. Consult a healthcare professional." (small grey text, always visible)
    - Injury count badge pill (orange tinted, like SyncStatusBadge)
    - IconButton to collapse (chevron_up)

    **State C — Acknowledged, collapsed:**
    Render a minimal TextButton.icon:
    - health_and_safety_outlined icon + "Show injury adaptations" label
    - Tapping expands back to State B

    **Constructor parameters:**
    ```dart
    const InjuryAdaptationBanner({
      super.key,
      required this.injuryContext,  // InjuryAdaptationContext
      required this.visible,        // bool — expanded/collapsed
      required this.onToggleVisibility,  // VoidCallback
      required this.onAcknowledgeDisclaimer,  // Future<void> Function(String injuryId)
    });
    ```

    **The widget does NOT manage its own expanded/collapsed state** — the parent screen manages it via `visible` + `onToggleVisibility`, matching the CycleAdjustmentExplainer pattern.

    When disclaimer is not acknowledged for all active injuries, render State A regardless of `visible` flag.

    The `onAcknowledgeDisclaimer` callback should be called once per unacknowledged injury ID. The widget iterates through `injuryContext.activeInjuries` and calls the callback for each one that hasn't been acknowledged. The parent screen is responsible for calling `ProfileRepository.acknowledgeInjuryDisclaimer` for each.

    Follow app theme: use `AppColors.brandPrimary`, `AppColors.textSecondary`, `Theme.of(context).textTheme` styles. Import from `../../../../app/theme.dart`.

    - Uses app theme colors and text styles
