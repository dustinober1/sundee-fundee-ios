  <behavior>
    The engine takes a ProgramV2 + list of active InjuryProfileModel and returns a new ProgramV2 with:

    1. **Exercise replacement:**
       - For each ProgramExercise in every session of every week:
         - Check if the exercise is contraindicated for any active injury (match injury.location keyword against exercise category/muscle groups using a static contraindication map).
         - If contraindicated, replace with a pattern-equivalent alternative:
           - Priority 1: Same category + overlapping muscle group (lookup via Exercises.all).
           - Priority 2: Same category, different muscle emphasis.
           - Priority 3: Static regression table entry (hardcoded safer alternatives for primary lifts).
           - Priority 4: Bodyweight regression from minimal safe set.
           - Priority 5: Annotated placeholder ("Consult coach — no safe automatic replacement found").
         - Set `injuryReplacedOriginal` to the original exercise name.
         - Set `injuryReplacementReason` to "Replaced — {location} injury limits {original}. Using {replacement} instead."
         - `isContraindicatedOriginal` defaults to false (set to true only when user reverts later, not in engine).
       - If NOT contraindicated, pass through unchanged (null injury fields).

    2. **Recovery prep injection:**
       - For each ProgramSession, populate `recoveryPrepExercises` with targeted warm-up/mobility exercises based on active injury locations.
       - Use a static map of injury location → recovery exercises (e.g., "knee" → Bird-Dogs + Bodyweight Lunges; "shoulder" → Banded Pull-Aparts + Face Pulls; "general" fallback).
       - Combine exercises from all active injuries. Deduplicate by exercise name. Cap at 5 exercises total.
       - Recovery exercises use low sets (2-3), moderate reps (8-15), short rest (0.5 min), and have notes prefixed with "Injury recovery prep —".

    3. **No-op behavior:**
       - If activeInjuries list is empty, return the base program unchanged (identity — same reference).

    4. **Immutability:**
       - Never mutate the input program. Always construct new ProgramV2/ProgramWeek/ProgramSession/ProgramExercise instances.
       - Follow exactly the `CycleProgramGenerator._copyProgram()` pattern.

    5. **Contraindication mapping (static, deterministic):**
       - "knee" injuries → contraindicate exercises with category "Squat Variations" or muscle groups containing "quads" or "glutes" in combination with deep-knee movements.
       - "shoulder" injuries → contraindicate exercises with category "Overhead Pressing", "Bench Press Variations", or muscle groups containing "shoulders".
       - "back"/"spine" injuries → contraindicate exercises with category "Hinge Variations", "Deadlift Variations", or muscle groups containing "back" with axial loading.
       - "hip" injuries → contraindicate exercises involving "glutes" + "hamstrings" with hip hinge patterns.
       - Location matching is case-insensitive contains check on injury.location field.
       - An exercise is contraindicated if ANY active injury matches it.

    6. **Regression table (static, for primary lifts):**
       - "Back Squat" → ["Goblet Squat", "Air Squats", "Leg Press"]
       - "Front Squat" → ["Goblet Squat", "Air Squats"]
       - "Conventional Deadlift (No Straps)" → ["Romanian Deadlift / RDL (No Straps)", "Trap Bar / Hex Bar Deadlift (No Straps)"]
       - "Flat Barbell Bench Press" → ["Dumbbell Bench Press", "Floor Press"]
       - "Strict Press / Military Press" → ["Lateral Raises", "Z-Press"]
       - Verify replacement IDs exist in Exercises.all before using; skip non-existent entries in the table.

    Test cases:
    - adaptProgram(program, []) → same program reference (identity)
    - adaptProgram(programWithBackSquat, [kneeInjury]) → Back Squat replaced, injuryReplacedOriginal="Back Squat", replacement is a Squat Variation or regression
    - adaptProgram(programWithBenchPress, [shoulderInjury]) → Bench Press replaced
    - adaptProgram(program, [kneeInjury]) → every session has non-empty recoveryPrepExercises
    - adaptProgram(program, [kneeInjury, shoulderInjury]) → recovery exercises from both, deduplicated, ≤5 total
    - adaptProgram(programWithNoContraindicated, [kneeInjury]) → exercises unchanged, recovery prep still added
    - Replacement reason string is non-empty and mentions injury location
    - New fields are null on non-replaced exercises
    - fromJson/toJson round-trip does NOT include injury-only fields (they are view-level, not persisted)
  </behavior>
