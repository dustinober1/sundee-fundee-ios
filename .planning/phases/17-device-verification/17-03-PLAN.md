Execute the scripted offline scenario (VERIFY-03) and auth flow matrix (VERIFY-04) on iOS simulator.

**Offline Scenario (VERIFY-03) — scripted steps, not exploratory:**

1. Reset simulator state: `xcrun simctl erase "iPhone 16 Pro"` then reboot and relaunch app
2. Sign in as test user (guest or email), complete onboarding
3. Go offline: Use Network Link Conditioner 100% Loss via Simulator menu (Features > Network Link Conditioner > 100% Loss), or disable Wi-Fi on the host Mac temporarily, or use `xcrun simctl status_bar "iPhone 16 Pro" override --cellularBars 0 --wifiBars 0` for visual indicator (note: this only changes status bar, not actual connectivity — prefer Network Link Conditioner or host network toggle)
4. Navigate to Workout tab, tap "Start Workout"
5. Add an exercise, log 3 sets (reps + weight for each)
6. Tap "Finish Workout"
7. Verify workout appears in History tab immediately (AsyncStorage persistence)
8. Force-kill app (swipe up in app switcher or `xcrun simctl terminate booted com.sundeefundee.app` — use actual bundle ID)
9. Relaunch app (still offline)
10. Verify workout still appears in History (crash recovery from AsyncStorage via `@sundee/active_workout` key and local workout repo)
11. Restore network (disable Network Link Conditioner / re-enable Wi-Fi)
12. Wait 10-15 seconds for Firestore sync
13. Verify workout synced — check Firebase Emulator UI at localhost:4000 if emulator is running, or verify no sync error in app logs
14. Record all results in triage report under "Offline Verification (VERIFY-03)" section

**Auth Flow Matrix (VERIFY-04):**

Test each auth path on the appropriate platform:

*iOS Simulator:*
1. **Guest sign-in:** Erase sim, launch app, tap "Continue as Guest" — lands on Dashboard
2. **Email/password sign-in:** Create account with test email, sign out, sign back in — lands on Dashboard
3. **Apple sign-in:** Tap Apple sign-in button — if simulator supports it (Xcode 15+ simulators can simulate Sign in with Apple), complete the flow. If not supported on simulator, document as "simulator limitation — deferred to P18 physical device"
4. **Guest-to-auth upgrade (CRITICAL PATH):**
   a. Sign in as guest
   b. Complete onboarding
   c. Start and complete a workout (so there's data to preserve)
   d. Navigate to Settings, tap "Create Account" (or equivalent upgrade CTA)
   e. Sign up with email/password
   f. Verify: all guest data preserved — workout appears in History, onboarding not re-shown
   g. If Firebase Emulator is running, verify /users/{uid} doc has migrated data

*Android Emulator (if available from Task 1):*
5. **Guest sign-in:** Launch, tap Guest — lands on Dashboard
6. **Email/password sign-in:** Create account, sign out, sign back in
7. **Google sign-in:** Tap Google button (if available in dev build)
8. **Guest-to-auth upgrade:** Same flow as iOS step 4

*Web (if available from Task 1):*

10. **Email/password sign-in:** Create account, test login
11. **Google sign-in:** Tap Google button, complete OAuth flow

Record all results in auth matrix table in triage report under "Auth Flow Matrix (VERIFY-04)" section.
