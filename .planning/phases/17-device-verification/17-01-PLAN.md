   - Expected: Dashboard directly, no onboarding re-shown, no routing flicker
   - If broken: check `@sundee/onboarding_profile` AsyncStorage key

5. **P3-4 — Guest onboarding persistence**

   - Expected: skips onboarding (reads from AsyncStorage)
