<objective>
Build the two Firebase Cloud Functions that power web subscription checkout and entitlement sync.

Purpose: Web users need a Stripe Checkout flow to subscribe, and successful payments must grant RevenueCat "premium" entitlement so mobile and web share a single entitlement source of truth. The webhook also writes premiumEntitlement to Firestore so web clients can read entitlement state via onSnapshot. These functions are the server-side bridge between Stripe payments and RevenueCat entitlements.

Output: Two deployed-ready Cloud Functions (createCheckoutSession onCall, stripeWebhook onRequest) with unit tests and Stripe npm dependency installed.
</objective>
