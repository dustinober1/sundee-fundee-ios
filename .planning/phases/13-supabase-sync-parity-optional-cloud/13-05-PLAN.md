    Test SyncNotifier state transitions using Riverpod's ProviderContainer pattern.

    - **SyncNotifier starts with correct auth state**: When supabase is configured and has a session → state.isAuthenticated == true
    - **SyncState.copyWith works correctly**: Unit test the copyWith method

    });
