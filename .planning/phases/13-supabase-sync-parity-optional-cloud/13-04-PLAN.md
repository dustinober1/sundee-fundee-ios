    A ConsumerWidget that displays an icon based on sync status:
    ```dart
    class SyncStatusBadge extends ConsumerWidget {
      const SyncStatusBadge({super.key});

      @override
      Widget build(BuildContext context, WidgetRef ref) {
        final syncState = ref.watch(syncProvider);
        return switch (syncState.status) {
          SyncStatus.disabled => const SizedBox.shrink(),
          SyncStatus.offline  => const Icon(Icons.cloud_off, color: Colors.grey),
          SyncStatus.pending  => const Icon(Icons.cloud_upload, color: Colors.orange),
          SyncStatus.syncing  => const SizedBox(
            width: 20, height: 20,
            child: CircularProgressIndicator(strokeWidth: 2),
          ),
          SyncStatus.synced   => const Icon(Icons.cloud_done, color: Colors.green),
          SyncStatus.error    => const Icon(Icons.cloud_off, color: Colors.red),
        };
      }
    }
    ```
    Key: `Key('sync-status-badge')` on the outer widget (wrap in a `KeyedSubtree` or add key to the SizedBox/Icon wrapper).

    **2. Update `flutter_app/lib/features/dashboard/dashboard_screen.dart`:**

    - Add imports for SyncStatusBadge, sync_provider.dart, auth_notifier.dart
    - Add `actions` to AppBar:
      ```dart
      appBar: AppBar(
        title: const Text('Dashboard'),
        actions: [
          const SyncStatusBadge(),
          // Show sign-in or settings icon based on auth state
          Consumer(builder: (context, ref, _) {
            final authState = ref.watch(authProvider);
            if (authState.isAuthenticated) {
              return IconButton(
                key: const Key('nav-settings'),
                icon: const Icon(Icons.settings),
                onPressed: () => context.go('/settings'),
              );
            }
            return IconButton(

              onPressed: () => context.go('/auth'),
            );
          }),
        ],
      ),
      ```

    IMPORTANT: The SyncStatusBadge renders SizedBox.shrink() when disabled (Supabase not configured), so it's invisible by default. The auth/settings nav icon appears in all cases — when not authenticated it shows login icon, when authenticated it shows settings icon.
