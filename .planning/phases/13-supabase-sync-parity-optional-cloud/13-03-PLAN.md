    **AuthState class:**
    ```dart
    class AuthState {
      final bool isLoading;
      final String? errorMessage;
      final bool isAuthenticated;
      final String? userEmail;

      const AuthState({
        this.isLoading = false,
        this.errorMessage,
        this.isAuthenticated = false,
        this.userEmail,
      });

      AuthState copyWith({
        bool? isLoading,
        String? errorMessage,
        bool? isAuthenticated,
        String? userEmail,
      }) => AuthState(
        isLoading: isLoading ?? this.isLoading,
        errorMessage: errorMessage,  // intentionally nullable to clear errors
        isAuthenticated: isAuthenticated ?? this.isAuthenticated,
        userEmail: userEmail ?? this.userEmail,
      );
    }
    ```

    **AuthNotifier (Riverpod 3.x NotifierProvider):**
    ```dart
    class AuthNotifier extends Notifier<AuthState> {
      @override
      AuthState build() {
        final supabase = ref.watch(supabaseClientProvider);
        if (supabase == null) return const AuthState();

        final session = supabase.auth.currentSession;
        return AuthState(
          isAuthenticated: session != null,
          userEmail: session?.user.email,
        );
      }

      Future<bool> signIn(String email, String password) async { ... }
      Future<bool> signUp(String email, String password) async { ... }
      Future<void> signOut() async { ... }
    }
    ```

    **signIn method:**
    - Set isLoading true, clear errorMessage
    - Call `supabase.auth.signInWithPassword(email: email, password: password)`
    - On success: set isAuthenticated true, isLoading false, userEmail from response
    - On `AuthException`: set errorMessage to `e.message`, isLoading false, return false
    - Return true on success

    **signUp method:**
    - Set isLoading true, clear errorMessage
    - Call `supabase.auth.signUp(email: email, password: password)`
    - On success: set isAuthenticated true (if email confirmation not required), isLoading false
    - On `AuthException`: set errorMessage to `e.message`, isLoading false, return false
    - Return true on success

    **signOut method:**
    - Call `supabase.auth.signOut()`
    - Reset state to AuthState(isAuthenticated: false)

    **Provider:**
    ```dart
    final authProvider = NotifierProvider<AuthNotifier, AuthState>(AuthNotifier.new);
    ```

    IMPORTANT: Do NOT handle sync state here. SyncNotifier listens to `onAuthStateChange` independently. AuthNotifier only manages the UI-facing auth state (loading, errors, user email).

    IMPORTANT: Use `ref.read(supabaseClientProvider)` inside methods (not `ref.watch`) since these are imperative calls, not reactive builds.
