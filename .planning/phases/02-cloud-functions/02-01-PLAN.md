Then create `functions/src/generateAIWorkout.ts` as a Firebase Functions v2 onCall function:

1. Import `onCall`, `HttpsError` from `firebase-functions/v2/https` and `defineSecret` from `firebase-functions/params`.
2. Define `const geminiApiKey = defineSecret('GEMINI_API_KEY');`
3. Export `generateAIWorkout = onCall({ secrets: [geminiApiKey], region: 'us-central1' }, async (request) => { ... })`.
4. Auth gate: if `!request.auth`, throw `new HttpsError('unauthenticated', 'Must be signed in to generate workouts.')`.
5. Extract the `WorkoutGenerationContext` fields from `request.data`. Validate that `timeMinutes`, `focus`, and `equipment` are present — throw `HttpsError('invalid-argument', ...)` if missing.
6. Build the Gemini prompt:
   - Create a system instruction that describes the AI as a strength training coach who creates personalized workouts.
   - Build the user prompt from the context fields: time budget, focus area, energy level, equipment, maxes, recent workouts, cycle phase, injuries, experience level, goal.
   - Request JSON output matching the GeneratedExercise[] shape: array of objects with { name, sets, reps, weightLb, restMinutes, notes, reasoning, bodyweightOnly }.
   - Also request a `coachingSummary` string.
7. Call Gemini using `@google/genai`:
   ```typescript
   import { GoogleGenAI } from '@google/genai';
   const ai = new GoogleGenAI({ apiKey: geminiApiKey.value() });
   const response = await ai.models.generateContent({
     model: 'gemini-2.5-flash',
     contents: userPrompt,
     config: {
       systemInstruction: SYSTEM_PROMPT,
       responseMimeType: 'application/json',
     },
   });
   ```
8. Parse the response: `const text = response.text;` then `JSON.parse(text)` in a try/catch. If parsing fails, throw `HttpsError('internal', 'Failed to parse AI response.')`.
9. Return the parsed workout data (exercises array + coachingSummary). The client constructs the full `GeneratedWorkout` object with id, createdAt, etc.
10. Use `firebase-functions/logger` for structured logging (log the uid, context summary, and any errors).
