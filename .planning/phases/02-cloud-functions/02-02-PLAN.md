  <name>Task 1: Implement createStripeCheckoutSession and stripeWebhook functions</name>
  <files>functions/src/createCheckoutSession.ts, functions/src/stripeWebhook.ts, functions/src/index.ts</files>
  <action>
**Create `functions/src/createCheckoutSession.ts`:**

1. Import `onCall`, `HttpsError` from `firebase-functions/v2/https`, `defineSecret` from `firebase-functions/params`, `getFirestore` from `firebase-admin/firestore`.
2. Define `const stripeSecretKey = defineSecret('STRIPE_SECRET_KEY');`
3. Export `createStripeCheckoutSession = onCall({ secrets: [stripeSecretKey], region: 'us-central1' }, async (request) => { ... })`.
4. Auth gate: if `!request.auth`, throw `HttpsError('unauthenticated', 'Must be signed in.')`.
5. Extract `{ priceId, successUrl, cancelUrl }` from `request.data`. Validate all three are non-empty strings.
6. Get the Firebase UID: `const uid = request.auth.uid;`
7. Check if the user already has a Stripe customer ID in Firestore:
   ```typescript
   const db = getFirestore();
   const userDoc = await db.collection('users').doc(uid).get();
   const existingCustomerId = userDoc.data()?.premiumEntitlement?.stripeCustomerId;
   ```
8. If `existingCustomerId` exists, retrieve the customer. Otherwise, create a new Stripe customer with `metadata: { firebaseUID: uid }` and the user's email from `request.auth.token.email`.
9. Create the checkout session:
   ```typescript
   const session = await stripe.checkout.sessions.create({
     customer: customer.id,
     line_items: [{ price: priceId, quantity: 1 }],
     mode: 'subscription',
     success_url: successUrl,
     cancel_url: cancelUrl,
   });
   ```
10. Return `{ url: session.url }`. This matches what the client expects from `stripe-checkout.ts`.
11. Use `logger` from `firebase-functions/logger` for all logging.

**Create `functions/src/stripeWebhook.ts`:**

1. Import `onRequest` from `firebase-functions/v2/https`, `defineSecret` from `firebase-functions/params`, `getFirestore` from `firebase-admin/firestore`.
2. Define `const stripeSecretKey = defineSecret('STRIPE_SECRET_KEY');` and `const stripeWebhookSecret = defineSecret('STRIPE_WEBHOOK_SECRET');`.
3. Export `stripeWebhook = onRequest({ secrets: [stripeSecretKey, stripeWebhookSecret], region: 'us-central1' }, async (request, response) => { ... })`.
4. Verify method is POST. Get `stripe-signature` header. If missing, return 400.
5. Verify the signature using `request.rawBody` (CRITICAL: not `request.body`):
   ```typescript
   const stripe = new Stripe(stripeSecretKey.value());
   const event = stripe.webhooks.constructEvent(
     request.rawBody,
     sig,
     stripeWebhookSecret.value()
   );
   ```
6. Handle `checkout.session.completed`:
   - Get the session object.
   - Retrieve the Stripe customer to get `metadata.firebaseUID`.
   - If uid found, write to Firestore:
     ```typescript
     await db.collection('users').doc(uid).set({
       premiumEntitlement: {
         active: true,
         stripeCustomerId: customerId,
         subscriptionId: session.subscription,
         activatedAt: new Date().toISOString(),
       }
     }, { merge: true });
     ```
7. Handle `customer.subscription.deleted`:
   - Retrieve customer metadata.firebaseUID.
   - Set `premiumEntitlement.active = false` in Firestore.
8. Return `response.json({ received: true })` for all events (Stripe expects a 200).
9. Log all events and any errors with `logger`.

Ensure all three functions are now exported.
