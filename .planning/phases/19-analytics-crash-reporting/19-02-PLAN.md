   - Import `useScreenTracking` from `@/src/hooks/useScreenTracking`.
   - Call `useScreenTracking()` at the TOP of the `RootLayout` function body, BEFORE any useEffect or conditional returns. This is critical -- if placed inside a conditionally-rendered child, it won't fire on tab changes.

2. **User properties on sign-in (ANLYT-03):**
   - Import `setUserProperties` from `@/src/firebase/analytics`.
   - Import `setCrashlyticsKeys` from `@/src/firebase/crashlytics`.
   - Inside `handleUserSignIn`, AFTER the profile persistence block (after the try/catch that calls `createOrUpdateUser`), add:
     ```
     // Set analytics user properties and Crashlytics custom keys
     const subscriptionTier: 'free' | 'premium' = 'free'; // Will be updated by entitlement changes
     void setUserProperties({ subscriptionTier, cycleTrackingEnabled: false });
     void setCrashlyticsKeys({ subscriptionTier, cyclePhase: 'unknown' });
     ```
   - Note: The initial sign-in sets defaults. The actual subscription_tier will be refined when EntitlementProvider loads (handled by existing entitlement context). Setting 'free' as default is correct because most users start free.

3. **Crashlytics user ID (ANLYT-05 supporting):**
   - Inside `handleUserSignIn`, after setting properties, add Crashlytics user ID for crash correlation:
     ```
     if (Platform.OS !== 'web') {
       try {
         const crashlytics = require('@react-native-firebase/crashlytics').default;
         void crashlytics().setUserId(user.uid);
       } catch { /* non-fatal */ }
     }
     ```

Do NOT modify the existing Firebase init useEffect, RevenueCat config, or migration retry logic.
