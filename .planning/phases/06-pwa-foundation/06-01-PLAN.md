<task type="auto">
  <name>Task 1: Generate PWA icons with Sharp</name>
  <files>scripts/generate-icons.mjs, public/icons/*.png, package.json</files>
  <action>
1. Add sharp to devDependencies: `npm install --save-dev sharp`

2. Create `scripts/generate-icons.mjs` that:
   - Uses Sharp to generate PNGs from programmatic SVG
   - Creates `public/icons/` directory
   - Generates 4 icons:
     - `icon-192.png` (192×192) — standard Android icon, dark #171717 background, white "SF" monogram, 80px corner radius
     - `icon-192-maskable.png` (192×192) — maskable variant with NO corner radius (full bleed), text scaled to fit inner 75% safe zone (font-size ~180)
     - `icon-512.png` (512×512) — same design as 192, scaled up
     - `apple-touch-icon.png` (180×180) — iOS icon, same design as 192 (iOS applies its own rounded corners)

3. Run the script: `node scripts/generate-icons.mjs`

4. Verify icons exist: `ls -la public/icons/`

SVG source for standard icons (192, 512, apple-touch):
```xml
<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512">
  <rect width="512" height="512" rx="80" fill="#171717"/>
  <text x="256" y="340" font-family="system-ui, -apple-system, sans-serif"
    font-size="220" font-weight="700" fill="white" text-anchor="middle">SF</text>
</svg>
```

SVG source for maskable icon (no rx, smaller text for safe zone):
```xml
<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512">
  <rect width="512" height="512" fill="#171717"/>
  <text x="256" y="330" font-family="system-ui, -apple-system, sans-serif"
    font-size="180" font-weight="700" fill="white" text-anchor="middle">SF</text>
</svg>
```

Note: Maskable icon text is smaller (180 vs 220) and positioned slightly higher to stay within 75% safe zone.

<task type="auto">
  <name>Task 2: Create manifest.ts metadata route</name>
  <files>src/app/manifest.ts</files>
  <action>
Create `src/app/manifest.ts` using Next.js App Router's built-in metadata route pattern:

```typescript
import type { MetadataRoute } from 'next'

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: 'Sundee-Fundee',
    short_name: 'SundeeFundee',  // 12 chars, no hyphen (Android truncation limit)
    description: 'Track your workouts and fitness goals',
    start_url: '/dashboard',
    display: 'standalone',
    background_color: '#ffffff',
    theme_color: '#171717',
    icons: [
      {
        src: '/icons/icon-192.png',
        sizes: '192x192',
        type: 'image/png',
      },
      {
        src: '/icons/icon-192-maskable.png',
        sizes: '192x192',
        type: 'image/png',
        purpose: 'maskable',
      },
      {
        src: '/icons/icon-512.png',
        sizes: '512x512',
        type: 'image/png',
      },
    ],
  }
}
```

Key values (from STATE.md locked decisions):
- `name: 'Sundee-Fundee'` (hyphenated brand name)
- `short_name: 'SundeeFundee'` (12 chars, no hyphen)
- `display: 'standalone'` (PWA requirement)
- `start_url: '/dashboard'` (main app entry point)
- `theme_color: '#171717'` (matches app foreground from globals.css oklch)
- `background_color: '#ffffff'` (matches app background)

Note: apple-touch-icon is NOT in manifest — iOS uses the `<link rel="apple-touch-icon">` from layout.tsx instead.
