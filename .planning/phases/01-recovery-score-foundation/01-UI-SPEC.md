## Spacing Scale

All tokens map directly to AppTheme.Spacing values. Source: AppTheme.swift.

| Token | Value | AppTheme Constant | Usage |
|-------|-------|-------------------|-------|
| xs | 4pt | AppTheme.Spacing.xs | Icon gaps, badge padding |
| sm | 8pt | AppTheme.Spacing.sm | Compact element spacing, row gaps |
| md | 12pt | AppTheme.Spacing.md | Input breakdown bar inner padding |
| lg | 16pt | AppTheme.Spacing.lg | Default element spacing, card padding |
| xl | 20pt | AppTheme.Spacing.xl | Section spacing within breakdown screen |
| xxl | 24pt | AppTheme.Spacing.xxl | Between score card and stat cards |
| xxxl | 32pt | AppTheme.Spacing.xxxl | Major section breaks |

Exceptions:
- `AppTheme.Spacing.md = 12pt` — AppTheme exception: existing design system constant, not introduced by this spec. 12pt is a multiple of 4 (grid-aligned) and is pre-defined in AppTheme.Spacing. Used for input breakdown bar inner padding.
- `AppTheme.Spacing.xl = 20pt` — AppTheme exception: existing design system constant, not introduced by this spec. 20pt is a multiple of 4 (grid-aligned) and is pre-defined in AppTheme.Spacing. Used for section spacing within the breakdown screen.
- Score ring diameter: 200pt (not on scale — sized for visual hierarchy as hero element)
- Ring stroke width: 20pt (proportional to ring diameter, not on spacing scale)
- Touch target minimum: 44pt for all tappable elements (HIG requirement)

## Typography

All fonts use AppTheme.Typography constants. Source: AppTheme.swift.

Exactly 4 sizes, exactly 2 weights.

| Role | AppTheme Constant | Base Size | Weight | Notes |
|------|-------------------|-----------|--------|-------|
| Score number (ring hero) | Typography.displayLarge | 32pt | bold | .serif (Playfair Display). Fixed size — not Dynamic Type |
| "Push Day" / "Rest Day" label | Typography.displaySmall | 20pt | bold | .serif. Fixed size — hero readability |
| Breakdown screen section title | Typography.headlineLarge | 18pt | bold | SF Pro |
| Input bar label | Typography.headlineSmall | 14pt | bold | SF Pro |
| Input bar explanation line | Typography.bodyMedium | 14pt | regular | Dynamic Type scalable |
| Trend chart axis labels | Typography.monoLarge | 14pt | regular | .monospaced. Dynamic Type scalable |
| Score sub-number on bars | Typography.monoLarge | 14pt | regular | .monospaced. Dynamic Type scalable |
| Badge text ("3/5 inputs") | Typography.labelMedium | 14pt | regular | Dynamic Type scalable |
| Sign-in prompt body | Typography.bodyMedium | 14pt | regular | Dynamic Type scalable |

Size scale (4 sizes): 14pt — 18pt — 20pt — 32pt

Weight scale (2 weights): bold (emphasis: score, labels, headings) — regular (body, supporting, mono)

Line heights:
- Fixed-size display fonts: SwiftUI default (approximately 1.2 for serif)
- Dynamic Type body: SwiftUI default lineSpacing (approximately 1.4–1.5 at default size)
- No custom lineSpacing overrides — trust UIFontMetrics behavior

### Recovery Score Color Coding (REC-01)

The ring arc and input bars use three semantic states:

| Score Range | Color | AppTheme Token | Hex |
|-------------|-------|----------------|-----|
| 70–100 (green / Push Day) | Recovery green | Color(red: 0.22, green: 0.70, blue: 0.29) | #38B249 (new — not in AppTheme yet) |
| 40–69 (yellow / Caution) | Recovery yellow | Color(red: 0.92, green: 0.76, blue: 0.18) | #EBC12E (new — not in AppTheme yet) |
| 0–39 (red / Rest Day) | Accent.orange | #f27319 | Existing AppTheme.Accent.orange |

Add these two new constants to AppTheme.Semantic or a new AppTheme.Recovery namespace:
- `AppTheme.Recovery.green` = Color(red: 0.22, green: 0.70, blue: 0.29) — green on cream: 3.7:1 (AA large text)
- `AppTheme.Recovery.yellow` = Color(red: 0.92, green: 0.76, blue: 0.18) — decorative only (arc fill), never used as text color
- Red zone reuses `AppTheme.Accent.orange` (#f27319) — consistent with existing destructive accent

### Cycle Phase Band Colors (D-07)

Used as background bands behind the trend chart line. Source: Claude's discretion (CONTEXT.md).

| Phase | Color | AppTheme Token | Opacity |
|-------|-------|----------------|---------|
| Menstrual | Accent.orange | #f27319 | 0.15 |
| Follicular | Recovery.green | #38B249 | 0.12 |
| Ovulation | Accent.gold | #d4a520 | 0.15 |
| Luteal | Text.secondary | #40537f | 0.10 |

All bands use low opacity to remain decorative — they must not obscure the recovery score line.

Accent reserved for:
- Primary recovery ring arc fill (color shifts by score zone)
- "Enable HealthKit" button (orange, AppButtonStyle.accent)
- Cycle phase band borders on trend chart (gold)
- Input bar sub-score arc fill (same green/yellow/orange logic)

## Component Inventory

### 1. RecoveryScoreCard (dashboard hero)

Placement: Top of DashboardView scroll, above existing cyclePhaseBanner. Replaces nothing — inserts as first VStack child after welcomeHeader.

Structure:
```
ArtDecoCard (padding: lg all sides)
  └── VStack(spacing: sm)
        ├── ZStack
        │     ├── Circle arc background (cream, opacity 0.3, stroke 20pt)
        │     ├── Circle arc fill (color by score zone, stroke 20pt, trimFrom: 0, trimTo: score/100)
        │     │     └── animation: .spring(response: 0.8, dampingFraction: 0.7) on appear
        │     └── VStack(spacing: xs)
        │           ├── Text(score) — Typography.displayLarge (32pt bold), Text.primary
        │           └── Text("Push Day" | "Rest Day" | "Rest") — Typography.displaySmall (20pt bold), zone color
        ├── Text("Recovery Score") — Typography.headlineSmall (14pt bold), Text.secondary
        └── HStack (conditional — only when partial data)
              └── Badge "X/5 inputs" — Typography.labelMedium (14pt regular), Text.secondary, Background.card, CornerRadius.small
```

Tap target: entire card navigates to RecoveryBreakdownView via NavigationStack push.
Accessibility: VoiceOver label = "Recovery score [N]. [Push Day / Rest Day]. Tap for breakdown."

### 2. RecoveryBreakdownView (sheet push from dashboard)

Navigation: NavigationStack push (not a sheet). Title: "Recovery Breakdown".

Structure:
```
ScrollView
  └── VStack(spacing: xl)
        ├── Section: "Today's Inputs"
        │     └── VStack(spacing: sm) — 5 input bars (or fewer if partial)
        │           └── InputBarRow (×5)
        ├── Divider (Accent.gold opacity 0.3)
        └── Section: "30-Day Trend"
              └── RecoveryTrendChart
```

### 3. InputBarRow

Structure:
```
VStack(spacing: xs)
  ├── HStack
  │     ├── SF Symbol icon (16pt, Text.secondary)
  │     ├── Text(label) — Typography.headlineSmall (14pt bold), Text.primary
  │     └── Spacer + Text(sub-score or "—") — Typography.monoLarge (14pt regular), zone color
  ├── GeometryReader → ZStack(alignment: .leading)
  │     ├── RoundedRectangle (Background.cream, height 8pt, CornerRadius.circle)
  │     └── RoundedRectangle (zone color, height 8pt, width: geo.size.width × sub-score/100)
  │           └── animation: .easeOut(duration: 0.5) on appear, staggered 0.1s per bar
  └── Text(explanation) — Typography.bodyMedium (14pt regular), Text.secondary
```

Grayed-out state (missing input — D-08):
- Sub-score shows "—", bar fill is Background.cream
- Explanation line shows "Enable [HealthKit / Apple Watch] to include this input"
- Row opacity: 0.5

### 4. RecoveryTrendChart

Uses SwiftUI Charts framework (consistent with VolumeChart, StrengthProgressionChart patterns).

Structure:
- Background: cycle phase colored bands (RectangleMark per phase date range, opacity per table above)
- Foreground: LineMark connecting daily recovery scores, color Text.primary, lineWidth 2pt
- X axis: date labels, Typography.monoLarge (14pt regular), Text.secondary, show every 7 days
- Y axis: 0–100, Typography.monoLarge (14pt regular), Text.secondary, gridlines at 40 and 70 (zone boundaries)
- PointMark on each data point: 4pt radius, color by zone
- Chart height: 200pt fixed

### 5. GuestPlaceholder (sign-in prompt — D-09)

Shown in place of RecoveryScoreCard when `authViewModel.isGuest == true`.

Structure:
```
ArtDecoCard
  └── VStack(spacing: md)
        ├── Image(systemName: "heart.circle") — 40pt, Accent.gold
        ├── Text("Sign in to unlock Recovery Score") — Typography.displaySmall (20pt bold)
        └── Button("Sign In") — AppButtonStyle.primary
```

## Interaction Contract

### Score Ring Animation

- Trigger: View appears (`.onAppear`) or score refreshes
- Behavior: Arc trim animates from 0 to `score/100` using `.spring(response: 0.8, dampingFraction: 0.7)`
- Color transition: instant (no cross-fade between zones — score is always known before animation)
- Repeat: does not repeat; only fires once per score load

### Input Bar Animation

- Trigger: RecoveryBreakdownView appears
- Behavior: Each bar animates `.easeOut(duration: 0.5)` staggered by `barIndex × 0.1s` delay
- Missing bars: render at full width immediately but grayed — no animation

### Trend Chart

- Trigger: Lazy load when user scrolls to chart section (use `.task` on chart container)
- Loading state: ProgressView (system spinner) centered in 200pt chart frame
- No animation on chart render (follow existing VolumeChart pattern — static render)

### Navigation

- Score card tap → NavigationStack push to RecoveryBreakdownView
- Back button: system back chevron, title "Dashboard"
- No sheets introduced in this phase

### Loading States

- Dashboard score card: While `RecoveryScoreViewModel.isLoading == true`, show ProgressView centered in ring frame (same 200pt container). Ring renders after load completes.
- Breakdown bars: Skeleton shimmer is out of scope — use ProgressView placeholder per bar (single horizontal RoundedRectangle, Background.card, animating opacity 0.4↔0.8)

### Error States

- HealthKit authorization denied: Show GuestPlaceholder-style card with SF Symbol "exclamationmark.shield" and copy from Copywriting Contract below
- Score computation failure (unexpected): Show "Score unavailable" text in ring center, Typography.bodyMedium (14pt regular), Text.secondary

## Accessibility Contract

- All tappable elements: minimum 44×44pt touch target (HIG)
- Score ring: VoiceOver reads "Recovery score [N out of 100]. [Push Day / Take It Easy / Rest Day]. Double-tap to view breakdown."
- Input bars: VoiceOver reads "[Input name]: [N] out of 100. [Explanation line]."
- Missing input bars: VoiceOver reads "[Input name]: not available. [Explanation line]."
- Color is never the sole indicator of meaning — the text label ("Push Day" / "Rest Day" / "Take It Easy") duplicates color information
- Trend chart: VoiceOver accessibility chart support via `.accessibilityChartDescriptor` (implement as text summary: "Recovery score trend over 30 days. Average: [N]. Range: [low]–[high].")
- Dynamic Type: body and label fonts scale via UIFontMetrics; display/headline fonts are fixed per existing AppTheme convention
