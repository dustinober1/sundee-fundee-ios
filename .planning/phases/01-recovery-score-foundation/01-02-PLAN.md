    **Step 1: Implement SleepDeduplicator.deduplicate** — replace the stub with:
    ```
    Algorithm:
    1. Filter to sleep stages only (countsAsSleep == true) — exclude .inBed and .awake
    2. Sort by start date ascending
    3. Separate into Watch intervals and non-Watch intervals
    4. Merge overlapping intervals within Watch set (standard interval merge: if current.start <= prev.end, extend prev.end to max(prev.end, current.end))
    5. Merge overlapping intervals within non-Watch set
    6. Remove non-Watch intervals that overlap with any merged Watch interval
    7. Sum all remaining merged intervals: endDate.timeIntervalSince(startDate)
    ```

    The merge is a standard sorted-array sweep line — O(n log n) for sort, O(n) for merge. No custom interval tree needed.

    Also add a convenience converter:
    ```swift
    /// Converts raw HKCategorySample data into SleepInterval domain types.
    /// This is the only function that takes HealthKit-adjacent parameters.
    public static func convertSamples(
        values: [(start: Date, end: Date, value: Int, sourceName: String)]
    ) -> [SleepInterval] {
        values.compactMap { sample in
            guard let stage = SleepStage(rawValue: sample.value) else { return nil }
            let source: SleepSource = sample.sourceName.lowercased().contains("watch") ? .watch : .phone
            return SleepInterval(start: sample.start, end: sample.end, source: source, stage: stage)
        }
    }
    ```
