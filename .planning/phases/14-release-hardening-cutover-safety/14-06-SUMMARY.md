## Key Decisions

1. **firebase_crashlytics ^4.3.0 vs ^4.5.0** — Plan specified `^4.5.0` which does not
   exist on pub.dev. Corrected to `^4.3.0` (resolves to 4.3.10, latest compatible).
   This is consistent with firebase_core `^3.14.0` (resolves to 3.15.2).

2. **Graceful Firebase degradation** — Firebase.initializeApp() is wrapped in
   try/catch so the app runs normally in development/test without firebase_options.dart.
   Production builds will have firebase_options.dart via `flutterfire configure`.
