Create firebase.json with SPA rewrite rules and add path URL strategy to Flutter web for proper deep link handling.

Purpose: DPLY-01 requires users can open and refresh deep links on Firebase-hosted web routes without 404 errors. Without SPA rewrites, Firebase returns 404 for any route other than /. Without path URL strategy, Flutter uses hash-based URLs which are non-standard.

Output: firebase.json at repo root, updated main.dart with usePathUrlStrategy().

<task type="auto">
  <name>Task 1: Create firebase.json with SPA rewrites and WASM headers</name>
  <files>firebase.json</files>
  <action>
    Create `firebase.json` at repository root:

    ```json
    {
      "hosting": {
        "public": "flutter_app/build/web",
        "ignore": [
          "firebase.json",
          "**/.*",
          "**/node_modules/**"
        ],
        "headers": [
          {
            "source": "**/*.wasm",
            "headers": [
              {
                "key": "Content-Type",
                "value": "application/wasm"
              }
            ]
          },
          {
            "source": "**",
            "headers": [
              {
                "key": "Cache-Control",
                "value": "no-cache, no-store, must-revalidate"
              }
            ]
          }
        ],
        "rewrites": [
          {
            "source": "**",
            "destination": "/index.html"
          }
        ]
      }
    }
    ```

    Key configuration:
    - `public`: Points to Flutter web build output
    - `headers`: WASM files get correct MIME type (Chrome blocks without it)
    - `rewrites`: All routes serve index.html (SPA pattern)
    - `ignore`: Standard ignores for clean deployment

    IMPORTANT: The Cache-Control header is aggressive (no-cache) for development. For production, consider adding cache busting for static assets while keeping SPA rewrite active.
  </action>
  <verify>
    - `cat firebase.json` shows valid JSON
    - `grep '"source": "\\*\\*"' firebase.json` matches (rewrite rule)
    - `grep 'application/wasm' firebase.json` matches (WASM header)
  </verify>
  <done>firebase.json exists with SPA rewrite rule and WASM MIME type header.</done>
</task>
