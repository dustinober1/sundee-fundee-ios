**Step 2: Create `src/hooks/use-weekly-volume.ts`**

Export `useWeeklyVolume()` → `{ data: WeeklyVolumePoint[], loading: boolean }`

`WeeklyVolumePoint` = `{ week: string; weekKey: string; volume: number }`
- `week`: display label like "Jan 6" (for XAxis)
- `weekKey`: "YYYY-MM-DD" of week start (for sorting)
- `volume`: total weight × reps for all sets that week

Query strategy:
1. `db.completedWorkouts.toArray()` → build `Map<workoutId, Date>` from `completedAt`
2. `db.completedSets.toArray()` → iterate all sets
3. For each set: look up workout date from map, compute `startOfWeek(date, { weekStartsOn: 1 })` (Monday start)
4. Format week start as `'yyyy-MM-dd'` key, accumulate `actualWeight * actualReps` per week key
5. Sort by weekKey ascending, `.slice(-12)` to show last 12 weeks only
6. Map to final format: `week = format(new Date(weekKey + 'T00:00:00'), 'MMM d')`, `volume = Math.round(total)`

**IMPORTANT:** Do NOT pad missing weeks with zero — only show weeks where user actually trained. Avoids misleading zero-volume bars.

Use the standard `isActive` cleanup flag pattern in `useEffect`. No dependencies (runs once on mount).

Imports: `date-fns` (`startOfWeek`, `format`), `@/lib/db/dexie`.

Mark `'use client'`.

**Step 1: Create `src/hooks/use-workout-frequency.ts`**

Export `useWorkoutFrequency()` → `{ data: Activity[], loading: boolean, totalWorkouts: number }`

`Activity` type (matches react-activity-calendar's expected shape):
```typescript
interface Activity {
  date: string;    // 'YYYY-MM-DD'
  count: number;   // number of workouts that day
  level: 0 | 1 | 2 | 3 | 4;  // intensity bucket
}
```

Query strategy:
1. `db.completedWorkouts.toArray()` → extract `completedAt` dates
2. Build `Map<string, number>` counting workouts per date (format each `completedAt` as `'yyyy-MM-dd'` key)
3. Generate full 365-day range: `eachDayOfInterval({ start: subYears(new Date(), 1), end: new Date() })`
4. Map every day to `Activity`: look up count from map (default 0), compute level: 0→0, 1→1, 2→2, 3-4→3, 5+→4
5. **Sort ascending by date** (react-activity-calendar requires sorted data)
6. Compute `totalWorkouts` as sum of all counts in the range

Return `{ data, loading, totalWorkouts }`.

Use `isActive` cleanup flag pattern. No dependencies (runs once on mount).

Imports: `date-fns` (`format`, `subYears`, `eachDayOfInterval`), `@/lib/db/dexie`.

Mark `'use client'`.

**Step 2: Create `src/components/progress/workout-heatmap.tsx`**

Export `WorkoutHeatmap` component.

1. Call `useWorkoutFrequency()` to get `{ data, loading, totalWorkouts }`

2. **Loading state:** Render `Skeleton` h-[160px] while loading

3. **Heatmap rendering** (even for zero data — react-activity-calendar renders a blank calendar which IS the empty state):
   ```tsx
   import ActivityCalendar from 'react-activity-calendar';
   ```
   
   Render `ActivityCalendar` with these props:
   - `data={data}` (full 365 days, zeros included)
   - `theme={{ light: ['#ebedf0', '#9be9a8', '#40c463', '#30a14e', '#216e39'] }}` (GitHub green palette)
   - `labels={{ totalCount: '{{count}} workouts in the last year' }}`
   - `showWeekdayLabels` (shows Mon/Wed/Fri labels)
   - `blockSize={12}` and `blockMargin={3}` for comfortable sizing on mobile
   - `fontSize={12}` for month labels

4. **Summary text** below the calendar: `<p className="text-sm text-muted-foreground mt-2">{totalWorkouts} workouts in the last year</p>`

5. **No separate empty state needed** — the heatmap with all-zero data naturally shows an empty calendar, which communicates "no activity yet" visually. The summary text will read "0 workouts in the last year."

6. Component renders ONLY the heatmap + summary — no Card wrapper.

**IMPORTANT:** react-activity-calendar is a default export, not named. Import as `import ActivityCalendar from 'react-activity-calendar'`.

Mark `'use client'`.
