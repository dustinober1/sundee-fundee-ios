<task type="auto">
  <name>Task 1: Create use-1rm-progress hook</name>
  <files>src/hooks/use-1rm-progress.ts</files>
  <action>
Create `src/hooks/use-1rm-progress.ts` that exports:

1. **`use1RMProgress(exerciseId: string)`** — returns `{ data: OneRMPoint[], loading: boolean }`
   - `OneRMPoint` = `{ date: string; estimated1RM: number }`
   - When `exerciseId` is empty/falsy, return empty data + `loading: false` early

2. **`useTrackedExercises()`** — returns `{ exercises: { id: string; name: string }[], loading: boolean }`
   - Queries `db.completedSets.toArray()`, extracts unique `exerciseId` values
   - Maps each exerciseId to its display name via `EXERCISES` from `@/data/exercises.ts` (find by `id` match)
   - Falls back to raw exerciseId as name if not found in EXERCISES list

3. **Epley helper** (not exported, internal):
   ```
   function epley(weight: number, reps: number): number {
     if (reps <= 1) return weight; // single rep = actual max
     return weight * (1 + Math.min(reps, 10) / 30);
   }
   ```
   Clamp reps at 10 before formula — Epley overestimates above 10 reps.

4. **Query strategy for `use1RMProgress`:**
   - `db.completedSets.where('exerciseId').equals(exerciseId).toArray()` — uses existing Dexie index
   - Extract unique `workoutId`s from results
   - `db.completedWorkouts.where('id').anyOf(workoutIds).toArray()` — get workout dates
   - Build `Map<workoutId, Date>` from completedWorkouts
   - Group sets by workoutId, for each group find max `epley(actualWeight, actualReps)`
   - Sort by date ascending
   - Map to `{ date: format(date, 'MMM d'), estimated1RM: Math.round(max1RM) }`

5. **Async pattern:** Use `useEffect` + `useState` with `isActive` cleanup flag (matches existing codebase pattern in current weight-progress-chart.tsx). Re-run effect when `exerciseId` changes.

6. **Imports:** `date-fns/format`, `@/lib/db/dexie` for `db`, `@/data/exercises` for `EXERCISES`.

Mark the file `'use client'` at the top.
