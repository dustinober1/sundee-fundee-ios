  <files>flutter_app/integration_test/support/firebase_emulator_test_harness.dart</files>
  <action>
In `FirebaseEmulatorTestHarness.initializeHarness()`, replace the two `throw StateError(...)` branches with early `return` statements. The test uses Riverpod provider overrides for all data — Firebase initialization is only needed when running against real emulators.

**Current code (lines to change):**
```dart
if (!_firebaseEnabled) {
  throw StateError(
    'ENABLE_FIREBASE=true is required for critical access integration checks.',
  );
}
if (!_useEmulators) {
  throw StateError(
    'USE_FIREBASE_EMULATORS=true is required to avoid live backend integration runs.',
  );
}
```

**Replace with:**
```dart
if (!_firebaseEnabled || !_useEmulators) {
  // Firebase plugins are unavailable on Linux desktop and unnecessary
  // when the test uses Riverpod provider overrides exclusively.
  return;
}
```

Collapse the two separate guard blocks into a single combined guard. The rest of the method body (Firebase.initializeApp, useAuthEmulator, useFirestoreEmulator, Settings) remains unchanged — it still runs when both flags are true (e.g., macOS local dev with emulators).

Do NOT change any other methods (seedVerificationAccount, checkpoint, etc.).
Do NOT change the class fields, constants, or VerificationAccount.
  </action>
