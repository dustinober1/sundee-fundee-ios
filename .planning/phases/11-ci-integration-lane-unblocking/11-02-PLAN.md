<objective>
Generate the Linux desktop platform files for flutter_app and rewrite the quality-integration CI job to run the critical access flow test on a Linux desktop target via xvfb-run — without Firebase emulators.

Purpose: Flutter integration_test requires a real device/desktop target (not just `flutter test`). Linux desktop is the only headless-capable Flutter target on ubuntu-latest. The test uses 100% provider overrides so Firebase emulators are unnecessary; removing the emulators:exec wrapper eliminates the Java/Node dependency and MissingPluginException failure.

<task type="auto">
  <name>Task 2: Rewrite quality-integration CI job for Linux desktop</name>
  <files>.github/workflows/flutter-release.yml</files>
  <action>
Replace the entire `quality-integration` job in `.github/workflows/flutter-release.yml` with a Linux desktop approach. The new job removes Firebase emulators (not needed — test uses provider overrides), removes Node/Java, adds GTK build deps, and runs via xvfb-run.

**Replace the current `quality-integration` job with:**

```yaml
  quality-integration:
    needs: quality
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: flutter_app
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.41.2'
          channel: 'stable'
          cache: true
      - name: Install Linux desktop build dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y clang cmake ninja-build pkg-config libgtk-3-dev liblzma-dev
      - name: Enable Linux desktop
        run: flutter config --enable-linux-desktop
      - name: Install dependencies
        run: flutter pub get
      - name: Run critical access integration test on Linux desktop
        run: |
          xvfb-run flutter test integration_test/critical_access_flow_test.dart -d linux -r expanded
      - name: Upload integration artifacts
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: quality-integration-logs
          path: |
            flutter_app/test-output
          if-no-files-found: warn
          retention-days: 30
```

**Key changes from the old job:**
1. REMOVED: `actions/setup-node@v4` step (no Node needed)
2. REMOVED: `npm install -g firebase-tools` step (no Firebase CLI needed)
3. REMOVED: `firebase emulators:exec` wrapper (no emulators needed)
4. REMOVED: All `--dart-define` flags (`ENABLE_FIREBASE`, `USE_FIREBASE_EMULATORS`, `SEED_VERIFICATION_ACCOUNT`) — without ENABLE_FIREBASE, the harness no-op guard from Plan 11-01 activates
5. ADDED: GTK build dependencies install step (`clang cmake ninja-build pkg-config libgtk-3-dev liblzma-dev`)
6. ADDED: `flutter config --enable-linux-desktop` step
7. CHANGED: Test command to `xvfb-run flutter test integration_test/critical_access_flow_test.dart -d linux -r expanded`
8. SIMPLIFIED: Upload artifacts path (removed firebase log files that no longer exist)

**Do NOT change** any other jobs (`quality`, `build-web`, `build-android`, `build-ios`). The `needs: [quality, quality-integration]` dependency in build jobs remains unchanged — once quality-integration passes, builds proceed.

**Do NOT change** the workflow triggers, name, or top-level `on:` block.
