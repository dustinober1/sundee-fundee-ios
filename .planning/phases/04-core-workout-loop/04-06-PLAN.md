       - `stop()`: clear timer state, cancel all notifications
       - Display tick: setInterval(100ms) to update `displayTime` string
       - Format: MM:SS for countdown modes, MM:SS for stopwatch
       - AppState listener: recalculate on foreground return
       - Cleanup: cancel all notifications and intervals on unmount
       - EMOM: track `currentMinute` via getEMOMCurrentMinute

       - After "GO", transition to actual timer start
