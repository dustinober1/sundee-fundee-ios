  <behavior>
    - createTimerState('rest', 90000) creates state with correct startedAt and durationMs
    - getElapsedMs returns correct elapsed time from startedAt minus totalPausedMs
    - getRemainingMs returns durationMs - elapsed, clamped to 0 minimum
    - pauseTimer sets pausedAt to current time
    - resumeTimer accumulates pause duration into totalPausedMs and clears pausedAt
    - getElapsedMs returns consistent value when timer is paused (uses pausedAt, not Date.now())
    - ForTime mode (durationMs=0) has getElapsedMs counting up, getRemainingMs always 0
    - AMRAP mode has getRemainingMs counting down from durationMs
    - isTimerComplete returns true when elapsed >= duration (for non-stopwatch modes)
    - getEMOMCurrentMinute returns floor(elapsed / 60000) + 1
  </behavior>
  <action>
    1. Create `src/domain/timers/timer-state.ts`:
       - `TimerMode` type: 'rest' | 'forTime' | 'amrap' | 'emom'
       - `TimerState` interface: { startedAt: number, pausedAt: number | null, totalPausedMs: number, durationMs: number, mode: TimerMode, intervalMs?: number }
       - `createTimerState(mode: TimerMode, durationMs: number, intervalMs?: number): TimerState` — sets startedAt to Date.now()
       - `getElapsedMs(state: TimerState, now?: number): number` — (now ?? state.pausedAt ?? Date.now()) - startedAt - totalPausedMs
       - `getRemainingMs(state: TimerState, now?: number): number` — Math.max(0, durationMs - getElapsedMs)
       - `pauseTimer(state: TimerState): TimerState` — returns new state with pausedAt set
       - `resumeTimer(state: TimerState): TimerState` — accumulates pause into totalPausedMs, clears pausedAt
       - `isTimerComplete(state: TimerState, now?: number): boolean` — elapsed >= duration (false for forTime where duration is 0)
       - `getEMOMCurrentMinute(state: TimerState, now?: number): number` — floor(elapsed / 60000) + 1
       - Accept optional `now` param in all calculation functions for deterministic testing
