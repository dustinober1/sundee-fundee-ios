    1. Create `useWorkoutSession.ts`:
       - State: `session: WorkoutSession | null`, `isActive: boolean`
       - On startWorkout(): call createSession(), save to AsyncStorage key `@sundee/active-workout`
       - Wrap each session action (addExercise, removeExercise, addSet, completeSet, reorderExercises) as dispatch functions that:
         a. Call the pure domain function
         b. Update React state
         c. Auto-save to AsyncStorage (debounced or on every set completion per research recommendation)
       - On finishWorkout(): convert WorkoutSession to WorkoutRecord, save via WorkoutRepo, clear AsyncStorage active workout
       - On mount: check AsyncStorage for active workout and restore if found (crash recovery)
       - Accept `isGuest` from AuthContext to select repo implementation
       - `getPreviousValues(exerciseId: string): Promise<{ weight: number; reps: number }[]>` — query last workout's sets for this exercise from WorkoutRepo for ghost text

    2. Create `useRestTimer.ts`:
       - State: `timerState: TimerState | null`, `remainingSeconds: number`
       - `start(seconds?: number)`: create timer state, schedule expo-notification for rest completion, start setInterval(100ms) for display updates
       - `skip()`: cancel notification, clear timer
       - AppState listener: on 'active', force re-render to recalculate from timestamps
       - Cleanup: cancel notification and clear interval on unmount
       - Accept `defaultSeconds` param (from settings)
       - Request notification permission on first use if not already granted

    3. Create `usePRDetection.ts`:
       - Loads ExerciseMax cache from ExerciseMaxRepo on workout start
       - `checkAndRecordPR(exerciseId, weight, reps)`: calls checkForPR, if PR detected:
         a. Save new max to ExerciseMaxRepo
         b. Update in-memory cache
         c. Return PRCheckResult for UI celebration
       - `recentPRs: PRCheckResult[]` — queue of recent PRs for toast display
       - Accept `uid` and `isGuest` for repo selection
  </action>
