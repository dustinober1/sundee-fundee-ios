**Download Drift web assets:**

Drift on web requires `sqlite3.wasm` and a web worker JS file in `flutter_app/web/`. Without these, the app will crash at DB init on web with `Could not initialize database` or `TypeError`.

1. Check the drift web documentation at https://drift.simonbinder.eu/platforms/web/ for the correct download URLs matching drift 2.31.x.
2. Download `sqlite3.wasm` using this executable fallback chain:
   ```bash
   cd flutter_app

   # Step A: Try building web first — drift_flutter 0.2+ may handle WASM automatically
   flutter build web 2>&1 && echo "Web build succeeded — WASM may be bundled" && exit 0

   # Step B: If build failed, find sqlite3.wasm in the pub cache (installed by sqlite3 package)
   SQLITE3_VER=$(dart pub deps --style=compact 2>/dev/null | grep -o "sqlite3 [0-9.]*" | awk '{print $2}')
   echo "Resolved sqlite3 version: $SQLITE3_VER"

   CACHED_WASM=$(find "$HOME/.pub-cache" -path "*sqlite3*" -name "sqlite3.wasm" -type f 2>/dev/null | sort -V | tail -1)
   if [ -n "$CACHED_WASM" ]; then
     cp "$CACHED_WASM" web/sqlite3.wasm
     echo "Copied sqlite3.wasm from pub cache: $CACHED_WASM"
   else
     # Step C: Download from the sqlite3 Dart package GitHub releases
     # Find the repo URL from pub.dev/packages/sqlite3 → Repository link → Releases
     REPO_URL=$(curl -s https://pub.dev/api/packages/sqlite3 | grep -o '"repository":"[^"]*"' | cut -d'"' -f4)
     echo "sqlite3 repo: $REPO_URL"
     echo "Download sqlite3.wasm for v${SQLITE3_VER} from ${REPO_URL}/releases"
     echo "Place the file at flutter_app/web/sqlite3.wasm"
   fi
   ```
   The key requirement: `flutter_app/web/sqlite3.wasm` must exist for Drift to function on web.

3. For the web worker: `drift_flutter` 0.2+ with `driftDatabase(name: ...)` bundles its own web worker internally. If `flutter build web` succeeds after step 2, no manual `drift_worker.js` is needed. If a build error references a missing worker, create a minimal one per drift docs at `web/drift_worker.js`.
