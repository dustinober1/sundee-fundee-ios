**Download Drift web assets:**

Drift on web requires `sqlite3.wasm` and a web worker JS file in `flutter_app/web/`. Without these, the app will crash at DB init on web with `Could not initialize database` or `TypeError`.

1. Check the drift web documentation at https://drift.simonbinder.eu/platforms/web/ for the correct download URLs matching drift 2.31.x.
2. Download `sqlite3.wasm` — this comes from the `sqlite3` Dart package's GitHub releases (https://github.com/nicbarker/tree-sitter-dart or simoncbinder/sqlite3.dart). Use the version compatible with the drift version installed. Typically:
   ```bash
   cd flutter_app
   # The exact URL depends on the sqlite3 package version resolved by pub.
   # Check: dart pub deps | grep sqlite3
   # Then download from the corresponding GitHub release
   curl -L -o web/sqlite3.wasm <URL_FROM_DRIFT_DOCS>
   ```
3. For the web worker, `drift_flutter` 0.2.x may generate or bundle the worker. Check if `driftDatabase(name: 'sundee_fundee', web: DriftWebOptions(...))` handles worker setup automatically. If a manual `drift_worker.js` is needed, download it from the drift releases or generate it per the drift web docs.

**Alternative approach if URLs are unclear:** Run `dart run drift_dev schema steps` or check if `drift_flutter` handles web setup automatically by creating a minimal test app and running `flutter build web`.
