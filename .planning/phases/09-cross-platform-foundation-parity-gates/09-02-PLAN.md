**Create Drift database** at `lib/data/database/app_database.dart`:
- Define a `Users` table with columns: `id` (integer autoIncrement), `name` (text), `experienceLevel` (text), `goal` (text), `createdAt` (dateTime with default currentDateAndTime)
- Annotate class with `@DriftDatabase(tables: [Users])`
- Class name: `AppDatabase extends _$AppDatabase`
- Two constructors: `AppDatabase(super.e)` (for test in-memory DB) and `AppDatabase.defaults() : super(driftDatabase(name: 'sundee_fundee'))` (for production)
- Set `schemaVersion => 1`
- Add `part 'app_database.g.dart';` at top
- Import `package:drift/drift.dart` and `package:drift_flutter/drift_flutter.dart`

**Run Drift code generation:**
```bash
cd flutter_app
dart run build_runner build --delete-conflicting-outputs
```
This generates `app_database.g.dart`. If it fails, check that `build_runner` and `drift_dev` are in dev_dependencies.

**Create connectivity service** at `lib/core/connectivity/connectivity_service.dart`:
- Wrap `connectivity_plus` package
- Expose a `Stream<bool> get isOnline` that maps `Connectivity().onConnectivityChanged` to a boolean (true if any result is NOT `ConnectivityResult.none`)
- Expose `Future<bool> checkConnectivity()` for one-shot checks
- Import from `package:connectivity_plus/connectivity_plus.dart`

**Create Riverpod providers:**

`lib/shared/providers/database_provider.dart`:
```dart
final databaseProvider = Provider<AppDatabase>((ref) {
  final db = AppDatabase.defaults();
  ref.onDispose(db.close);
  return db;
});
```

`lib/shared/providers/connectivity_provider.dart`:
```dart
final connectivityServiceProvider = Provider<ConnectivityService>((ref) {
  return ConnectivityService();
});

final isOnlineProvider = StreamProvider<bool>((ref) {
  final service = ref.watch(connectivityServiceProvider);
  return service.isOnline;
});
```

**Verify:** `dart run build_runner build` succeeds. `flutter analyze` shows no errors in these files.
