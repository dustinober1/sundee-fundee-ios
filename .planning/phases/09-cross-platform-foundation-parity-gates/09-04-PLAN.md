<task type="auto">
  <name>Task 1: Install Android SDK and CocoaPods, verify both platform builds</name>
  <files></files>
  <action>
**Android SDK setup:**

1. Check if Android SDK is already available:
   ```bash
   flutter doctor -v 2>&1 | grep -A5 "Android toolchain"
   ```

2. If Android SDK is missing, install via Homebrew:
   ```bash
   brew install --cask android-commandlinetools
   ```
   Then install required SDK components:
   ```bash
   # Accept licenses
   yes | sdkmanager --licenses
   # Install build tools and platform
   sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
   ```
   Set `ANDROID_HOME` if not already set:
   ```bash
   export ANDROID_HOME="$HOME/Library/Android/sdk"
   ```
   If Homebrew installed to a different location, find it:
   ```bash
   find /opt/homebrew /usr/local -name "sdkmanager" 2>/dev/null
   ```

3. Verify Android build:
   ```bash
   cd flutter_app && flutter build apk --debug
   ```
   This must exit 0. If it fails with a Java version issue, install the required JDK:
   ```bash
   brew install openjdk@17
   ```

**CocoaPods setup:**

1. Check if CocoaPods is installed:
   ```bash
   which pod && pod --version
   ```

2. If missing, install via Homebrew (preferred over gem to avoid permission issues):
   ```bash
   brew install cocoapods
   ```
   If brew is unavailable or fails, fall back to:
   ```bash
   sudo gem install cocoapods
   pod setup
   ```

3. Verify iOS build:
   ```bash
   cd flutter_app && flutter build ios --no-codesign
   ```
   This must exit 0. If it fails with pod install issues, run:
   ```bash
   cd flutter_app/ios && pod install && cd ..
   flutter build ios --no-codesign
   ```

**Final verification:**
```bash
cd flutter_app && flutter doctor -v
```
Both Android and iOS sections should show checkmarks (or only minor non-blocking warnings like "Android Studio not installed").
