This adds `esbuild` and `esbuild-wasm` to `serverExternalPackages`. No other changes needed.

2. Update `tsconfig.json` to exclude the SW entry point:

Add `"src/app/sw.ts"` to the `exclude` array. The SW uses `/// <reference no-default-lib="true" />` which conflicts with the `dom` lib used by the rest of the app.

```json

}
```

Without this exclusion, TypeScript will emit type errors about `self` and `fetch` type conflicts between webworker and dom libs.

<task type="auto">
  <name>Task 3: Create service worker and route handler</name>
  <files>src/app/sw.ts, src/app/serwist/[path]/route.ts, middleware.ts</files>
  <action>
1. Create `src/app/sw.ts` — service worker entry point:

```typescript
/// <reference no-default-lib="true" />
/// <reference lib="esnext" />
/// <reference lib="webworker" />
import { defaultCache } from "@serwist/turbopack/worker";
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";
import { NetworkOnly, Serwist } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

declare const self: ServiceWorkerGlobalScope;

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    // MUST be first — prevents defaultCache cross-origin handler from caching Supabase
    {
      matcher: ({ url }) => url.hostname.endsWith(".supabase.co"),
      handler: new NetworkOnly(),
    },
    ...defaultCache,
  ],
  fallbacks: {
    entries: [
      {
        url: "/offline",
        matcher({ request }) {
          return request.destination === "document";
        },
      },
    ],
  },
});

serwist.addEventListeners();
```

Critical: The Supabase NetworkOnly rule MUST be first in runtimeCaching. `defaultCache` has a cross-origin NetworkFirst handler (1-hour TTL) that would otherwise cache Supabase responses.

2. Create `src/app/serwist/[path]/route.ts` — route handler:

```typescript
import { spawnSync } from "node:child_process";
import { createSerwistRoute } from "@serwist/turbopack";

const revision =
  spawnSync("git", ["rev-parse", "HEAD"], { encoding: "utf-8" }).stdout.trim() ||
  crypto.randomUUID();

export const { dynamic, dynamicParams, revalidate, generateStaticParams, GET } =
  createSerwistRoute({
    additionalPrecacheEntries: [{ url: "/offline", revision }],
    swSrc: "src/app/sw.ts",
    useNativeEsbuild: true,
  });
```

Note: Path `[path]` not `[...path]` — critical for sourcemap resolution.

3. Update `middleware.ts` matcher to exclude `/serwist/` paths:

Current matcher excludes `sw.js`. With @serwist/turbopack, the SW is served at `/serwist/sw.js`. Add `serwist/.*` to the exclusion pattern.

Change:
```typescript
'/((?!_next/static|_next/image|favicon.ico|manifest\\.json|sw\\.js|workbox-.*\\.js|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)'
```

To:
```typescript
'/((?!_next/static|_next/image|favicon.ico|manifest\\.json|sw\\.js|workbox-.*\\.js|serwist/.*|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)'
```

This prevents unnecessary Supabase auth processing on SW file requests.
