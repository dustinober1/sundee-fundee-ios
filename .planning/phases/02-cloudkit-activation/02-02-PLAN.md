<objective>
Replace silent store deletion on CloudKit container failure with a user-visible error alert and safe local-persistent fallback.

Purpose: Currently, if the CloudKit container fails to open, the app silently deletes local store files and falls back to in-memory — losing user data without warning. SYNC-04 requires the user to see an error message, and data must be preserved.
Output: Container failure surfaces as SwiftUI alert; local data is never silently deleted.
</objective>
