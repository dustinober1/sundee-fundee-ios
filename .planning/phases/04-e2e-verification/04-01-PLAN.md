    **Assertion strategy**: After clicking "Complete Workout", the `handleWorkoutComplete` function calls `router.back()`. Since we navigated directly to `/workout/...`, going back will likely return to an empty history. Instead, assert one of:
    - Option A: After completing, verify IndexedDB has the completed workout by using `page.evaluate()` to check Dexie:
      ```typescript
      const workoutCount = await page.evaluate(async () => {
        const request = indexedDB.open('StrengthApp', 4);
        return new Promise<number>((resolve) => {
          request.onsuccess = (event) => {
            const db = (event.target as IDBOpenDBRequest).result;
            const tx = db.transaction('completedWorkouts', 'readonly');
            const store = tx.objectStore('completedWorkouts');
            const countReq = store.count();
            countReq.onsuccess = () => resolve(countReq.result);
            countReq.onerror = () => resolve(0);
          };
          request.onerror = () => resolve(0);
        });
      });
      expect(workoutCount).toBeGreaterThan(0);
      ```
    - Option B: Navigate to `/dashboard` after completion and verify a completed workout indicator shows

    **Prefer Option A** — it's a direct assertion on the data, not dependent on dashboard UI rendering.
