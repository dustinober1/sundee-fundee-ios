    - Test: hook captures beforeinstallprompt event and stores it in androidPrompt state
    - Test: hook detects iOS Safari via user agent when not standalone
    - Test: dismiss() sets sessionStorage flag and isDismissed=true
    - Test: isDismissed initializes to true when sessionStorage flag already set
    - Test: triggerAndroid() calls prompt() on captured event and sets androidPrompt to null after
  </behavior>
  <action>
1. Create `pwa/src/hooks/` directory.

2. Create `pwa/src/hooks/useInstallPrompt.ts`:
   - Define `BeforeInstallPromptEvent` interface (extends Event with `prompt(): Promise<void>` and `userChoice: Promise<{outcome: 'accepted' | 'dismissed'}>`)
   - Export `useInstallPrompt()` hook that returns `{ androidPrompt, isIOS, isStandalone, isDismissed, triggerAndroid, dismiss, showPrompt }`
   - `showPrompt` is a computed boolean: `(androidPrompt !== null || isIOS) && !isDismissed && !isStandalone`
   - Standalone detection: `window.matchMedia('(display-mode: standalone)').matches || (navigator as any).standalone === true`
   - iOS detection: `/iPad|iPhone|iPod/.test(navigator.userAgent)` AND not standalone
   - On mount (if not standalone): add `beforeinstallprompt` event listener, `e.preventDefault()`, store event
   - `triggerAndroid()`: call `androidPrompt.prompt()`, await `userChoice`, if dismissed call `dismiss()`, set androidPrompt to null
   - `dismiss()`: `sessionStorage.setItem('installPromptDismissed', '1')`, set isDismissed=true
   - `isDismissed` initial state: `sessionStorage.getItem('installPromptDismissed') === '1'`

3. Create `pwa/src/hooks/useInstallPrompt.test.ts`:
   - Mock `window.matchMedia`, `navigator.userAgent`, `sessionStorage`
   - Test standalone suppression (matchMedia returns matches: true)
   - Test Android flow (dispatch beforeinstallprompt event, verify androidPrompt captured)
   - Test iOS detection (set iPad user agent, verify isIOS=true)
   - Test dismiss behavior (sessionStorage set, isDismissed=true)
   - Test already-dismissed initialization
   - Use `renderHook` from `@testing-library/react`

4. Create `pwa/src/components/InstallBanner.tsx`:
   - A bottom-fixed banner component that receives props from useInstallPrompt
   - Props: `{ isIOS: boolean; onInstall: () => void; onDismiss: () => void }`
   - iOS variant: shows share icon (unicode arrow up from square: "\u{E38D}" or text "[Share]") + "Tap Share then 'Add to Home Screen'" text + dismiss X button
   - Android variant: shows "Install Sundee Fundee" text + "Install" button (calls onInstall) + dismiss X button
   - Styled with Art Deco theme: cream (#F4F0DF) background, navy (#0D1A40) text, orange (#F2731A) install button
   - Position: fixed bottom, full width, with padding and subtle top shadow
   - Accessible: role="banner", aria-label, button has clear text
  </action>
