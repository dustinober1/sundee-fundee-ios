<objective>
Wire guest-to-permanent account upgrade into sign-in.tsx so that anonymous users who sign up retain all their locally stored data instead of starting fresh.

Purpose: Closes the AUTH-07 gap -- the upgrade mechanism (useGuestSignIn.upgrade) is fully implemented but sign-in.tsx never calls it. Guest users currently lose all workout history, cycle logs, and injury profiles when they create a permanent account.

Output: Modified sign-in.tsx with isAnonymous guards in all three auth handlers, refactored Apple/Google hooks exposing getCredential, EmailAuthProvider exported from platform auth wrappers, and comprehensive tests.
</objective>
