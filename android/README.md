# Sundee Fundee - Native Android

This is a native Android port of the Sundee Fundee fitness application.

## Overview

Sundee Fundee is a CrossFit-inspired workout tracking app that helps athletes:
- Follow structured training programs
- Track max lifts and benchmarks
- Execute workouts with timer functionality
- Monitor training cycles and recovery
- Generate AI-powered custom workouts

## Architecture

This Android application follows Clean Architecture with:
- **UI Layer**: Jetpack Compose with Material Design 3
- **Domain Layer**: Business logic and use cases
- **Data Layer**: Repositories, Room database, and Firebase services

## Status

This project is currently in the initial development phase (Phase 1.1 - Project Setup).
